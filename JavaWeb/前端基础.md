# 前端基础

本章节讲解前端基础内容，并不是所有内容，有需要的话可以自行学习。

- 前端：我们网站的页面，包括网站的样式、图片、视频等一切用户可见的内容都是前端的内容。
- 后端：处理网站的所有数据来源，比如我们之前在数据库中查询数据，而我们查询的数据经过处理最终会被展示到前端，而用于处理前端数据的工作都是由后端来完成。

相当于前端仅仅是一层皮，他决定了整个网站的美观程度，我们可以自由编排页面的布局，甚至特效；而灵魂是后端，如何处理用户的交互，如何处理查询数据时后端的职责。

## HTML页面

我们前面学习了XML语言，他是一种标记语言，我们需要以成对标签的格式进行填写，但是它是专门用于保存数据，而不是展示数据，而HTML相反，它专用于展示数据。

### 第一个HTML页面

我们前面已经了解，通过浏览器可以直接浏览xml文件，而浏览器一般是用于浏览HTML文件的，以HTML语言编写的内容，会被浏览器识别成一个页面。

比如，我们可以创建一个html文件看浏览器如何识别，使用IDEA同样也可以编写html语言，我们新建一个WEB模块，进入后发现，项目中没有任何内容，我们右键新建一个HTML文件，创建后发现：

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Title</title>
</head>
<body>

</body>
</html>
```

我们发现，它和xml长得基本一样，而且还自带一些标签，那么我们通过浏览器来浏览整个html文件。

标签位置显示了网页的名称为Title，并且显示了一个IDEA的图标作为网页图标。

现在，我们进行修改：

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>lbw的直播间</title>
</head>
<body>
    现在全体起立
</body>
</html>
```

发现浏览器都发生了改变。

我们可以在设置->工具->Web浏览器和预览中重新加载页面规则改为变更时，这样浏览器会自动更新我们编写的内容。

我们还可以在页面中添加图片，将图片放到html的同级目录下，命名为xxx.jpg，在body节点中添加以下内容：

```html
<img width="300" src="xxx.jpg" alt="哈哈">
```

width表示像素，src表示图片，alt则是图片加载失败后显示的别名。

我们同样可以插入b站的视频，在视频下方点击分享的嵌入代码：

```html
<iframe src="//player.bilibili.com/player.html?isOutside=true&aid=115033719703142&bvid=BV17gbsz9ETA&cid=31722374941&p=1" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true"></iframe>
```

### HTML语法规范

一个HTML文件一般分为两个部分：

- 头部：一般包含页面的标题，页面的图标，还有页面的设置，这里也可以导入css，js等内容。
- 主体：整个页面所有需要显示的内容全部在主体编写。

我们先来看头部：

```html
<head>
    <meta charset="UTF-8">
    <title>lbw的直播间</title>
</head>
```

首先，meta标签用于定义页面的一些元信息，这里使用它来定义了一个字符集（编码格式），一般是UTF-8，下面的title则是页面的标题，会显示在浏览器的上方，我们先来给页面设置一个图标，图标可以在这里找：https://iconpark.oceanengine.com/home

下载到项目目录，命名为xxx.png，在html头部添加以下内容：

```html
<link rel="icon" href="xxx.png" type="image/x-icon" />
```

- rel用于定义当前文档与图片之间的关系（其他属性以后会学到）。
- href用于指定图片的路径和文件名。
- type用于指定图片的MIME类型，帮助浏览器识别资源格式。如果是png格式，则改为type=“image/png”。

我们再来看主体，我们可以在主体内部编写该页面展示的所有内容，比如我们之前用到了img标签来展示一个图片，其中每一个标签都称为一个元素：

```html
<img width="300" src="xxx.jpg" alt="哈哈">
```

我们发现，这个变迁只存在以恶搞并没有成对出现，html中有些标签是单标签，有些是双标签，html中，不允许交叉嵌套，再出现交叉嵌套时，浏览器不会提示这些错误，而是尝试解析，并帮助我们进行修复：

```html

            scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true">
</body>
</iframe>
```

很明显上面的代码已经出现交叉嵌套的情况了，但是依然能够在浏览器中正确地显示。

## CSS样式

之前我们编写的页面非常基础，我们只能通过一些基本的属性来排列我们的页面元素，那么如何实现高度自定义呢，我们需要用到CSS来自定义样式，首先我们创建后缀为.css的文件。

首先我们需要在HTML文件的头部添加：

```html
<link href="style.css" rel="stylesheet">
```

我们在CSS文件中添加以下内容：

```css
body{
    text-align:center;
}
```

我们发现，网页的内容全部变为居中显示了，这正是css在生效，相当于我们现在给页面添加了自定义样式规则。

当然，我们也可以选择不适用CSS，而是直接对某个元素添加样式：

```html
<body style="text-align:center;">
...
```

这样的效果其实是等同于上面的css文件的，相当于我们直接把样式定义在指定元素上。

也可以在头部直接定义样式，而不俗hi使用外部文件：

```html
<style>
    body{
        text-align:center;
    }
</style>
```

这三种都可以，推荐第一种。

### CSS选择器

我们首先来了解一下选择器，那么什么是选择器呢？我们想要自定义一个元素的样式，那么我们肯定要去选择某个元素，只有先找到要自定义的样式，我们才能开始编写样式。

我们上面的例子使用的就是标签名选择器，它可以快速选择页面中所有指定的标签，比如我们之前使用的就是body标签，那么相当于页面中所有的body元素全部都使用此样式，那么我们现在来试试看选择页面中的input标签：

```css
input{
    width:200px;
}
```

我们发现，页面中所有的input元素宽度全部设定为200个像素。

样式编写完成后，如果只有一个书信那个，可以不带分号，若多个属性，则每个属性后面都添加一个分号。

因此，一个标签选择器的格式为

```css
标签名称{
    属性名称：属性值
}
```

我们还可以设定输入框的字体大小，行高等等：

```css
input{
    width:200px;
    font-size:20px;
    line-height:40px;
}
```

我们现在就可以通过选择器快速地去设置某个元素的样式了；那么如何单独设置某个元素呢，这里我们运用id选择器，之前我们提到，每个元素都可以有一个id属性，我们可以当作一个跳转的锚点使用，现在，我们可以使用css来定位：

我们先为元素添加id属性：

```html
<h1 id="title">
    我的网站
</h1>
```

现在，使用css来选择我们的元素，并设定一个属性，选择某个id需要在前面加一个#号

```css
#title{
    color:red;
}
```

虽然id选择器已经可以很方便的指定某个元素，但是如果我们希望n个但不是元素被选择，id选择器就无法实现了，因为每个元素的id是唯一的，不允许出现重复id的元素，因此，我们来讲一下类选择器。

每一元素都可以有一个class属性，表示当前元素属于某个类（这里的类与Java的类不是一个概念）一个元素可以属于很多个类，一个类也可以被很多个元素使用：

```html
<form>
    <div >
        <label class="target">
            账号：
            <input type="target" placeholder="Username...">
        </label>
    </div>
    <div>
        <label class="target">
            密码：
            <input type="password" placeholder="Password...">
        </label>
    </div>
</form>
```

在上面的例子中，两个label元素都使用了target类（我们自己定义的），现在我们在css文件中编写了一些内容来以类进行选择：

```css
.target{
    color:blue;
}
```

我们发现，两个标签的文本内容变成了蓝色。

注意在进行类选择时，我们需要在类名前面加上.来表示。

### 组合选择器和优先级问题

我们也可以让多个选择器共用一个css样式：

```css
.target,#title{
    color:red;
}
```

只需要并排写即可，注意中间需要添加一个逗号用于分割，我们也可以使用*来一次性表示所有的元素：

```css
*{
    color:red;
}
```

我们还可以选择位于某个元素内的某个元素：

```css
div label{
    color:red;
}
```

这样，就会选择所有位于div中的label元素。

我们接着来看一下选择器的优先级：

### 自定义边框

我们来看看，如何使用css控制一个div板块的样式，首先编写以下代码，相当于一个div嵌套一个div：

```html
<div id="outer">
    <div id="inner">
       
    </div>
</div>
```

现在编写以下自定义的css样式，我们将div设定为固定大小，并且将背景颜色设定为绿色：

```css
#outer{
    background:palegreen;
    width:300px;
    height:300px;
}
```

此时我们发现，页面存在空隙，这是因为浏览器给我们添加了一个边距属性，我们只需要覆盖此属性并将其设定为0即可：

```css
body{
    margin:0;
}
```

现在，我们给内部嵌套的div也设定一个大小，并将颜色设定为橙色：

```css
#inner{
    background:darkorange;
    width:100px;
    height:100px;
}
```

我们发现，内部的div元素位于左上角，同理，我们可以用百分比设定大小：

```css
#inner {
    background: darkorange;
    width: 100%;
    height: 100%;
}
```

百分比是根据外部的大小来分配的，100%表示使用了外部的全部大小。

我们可以为一个元素设定边距，比如：

```css
#outer {
    background: palegreen;
    width: 300px;
    height: 300px;
    padding: 10px;
}
```

此时，外部元素作为内部元素的边距。

## JavaScript语言

也称js，是我们整个前端基础的重点内容，只有了解了JS语言，我们才能了解前端如何与后端 交互。

JS语言与Java没有任何关系，正如周杰伦与周杰没有任何关系，它是一门解释型语言，不需要进行编译，甚至可以在浏览器的命令窗口中运行。

它相当于是前端静态页面的一个补充，它可以让一个普通的页面在后台执行一些程序，比如我们点击一个按钮，我们可能希望执行某些操作，比如下载文件，页面跳转，页面弹窗，进行登录等等，都可以使用JS来帮助我们实现。

我们先来看看简单的JS程序：

```js
const arr = [0, 2, 1, 5, 9, 3, 4, 6, 7, 8]

for (let i = 0; i < arr.length; i++) {
    for (let j = 0; j < arr.length - 1; j++) {
        if(arr[j] > arr[j+1]){
            const tmp = arr[j]
            arr[j] = arr[j+1]
            arr[j+1] = tmp
        }
    }
}

window.alert(arr)
```

冒泡排序，大家都很熟悉，我们可以直接在页面的头部引用此js文件，浏览器会在加载时自动执行js文件中编写的内容：

```html
<script src="test.js"></script>
```

接着，我们来看看基本语法。

### JS基本语法

在js中，定义变量与Java有些不同，定义一个变量可以使用let关键字或者var关键字，IDEA推荐你使用let；因为var存在一定缺陷（这里不做讲解）：

```js
let a=10;
a++;
window.alert(a)
```

结果为11，JS结尾不用加分号。

js并不是Java那样强类型语言（任意变量的类型一定是明确的），它是一门弱类型语言，变量的类型并不在一开始确定，因此我们在定义变量时无需指定变量的确切类型，而是运行时动态分析。

当然，如果此时改变赋值a，变成字符串，也可以通过。

我们接着看，JS存在的基本数据类型：

- Number：数字类型（包括小数和整数）
- String：字符串类型（可以使用单引号或者双引号）
- Boolean：布尔类型（与Java一致）

还存在一些特殊值：

- underfined：未定义-变量声明但不赋值默认为undefined

- null：空值等同于Java中的null

- NaN：非数字-值不是合法数字，比如：

	```js
	window.alert(100/'xx')
	```

我们可以使用typeof关键字来查看当前变量值的类型：

```js
let a=10;
console.info(typeof a)
a='Hello World'
console.info(typeof a)
```

### JS逻辑运算和流程控制

我们接着来看看JS中的关系运算符，包括以下8个：大于，小于，小于等于，大于等于，相等（`==`），不等，全等（`===`），不全等（`!==`）。

关系运算符与Java的使用方法一致，不过还可以进行字符串比较，有点像C++的语法：

```js
console.info(666>777)
console.info('aa'>'bb')
```

那么，相等与全等有什么区别呢：

```js
console.info('10'==10)
console.inof('10'===10)
```

在Java中，若运算符两边是不同的基本数据类型，会直接得到false，而JS却不像这样，我们发现字符串的10居然等于数字10，使用全等判断才会是Java得到的结果。

==的比较规则是：当操作数类型一样时，比较的规则和恒等运算符一样，都相等才相等，如果两个操作数是字符串，则进行字符串的比较，如果里面有一个操作数不是字符串，那么两个操作数通过Number()方法进行转换，转换成数字进行比较。

因此，我们上面进行的判断实际上是运算符两边都进行数字转换得到的结果进行比较，自然得到了true。

我们接着来看逻辑运算，JS中包括&,||,&,|,?等，我们先来看看位运算符：

```js
console.info(4&7)
console.info(4|7)
```

得到的结果与Java一样。那么我再来看看逻辑运算：

```js
console.info(true || false)
```

对于boolean变量的判断，是与Java一致的，但是JS也可以使用非Boolen类型变量进行判断：

```js
console.info(!0)
console.info(!1)
```

和C/C++语言一样，0代表false，非0代表true，那么字符串呢？

```js
console.info(!"a")
console.info(!"")
```

我们发现，空串为false，非空串为true，我们再来看看：

```js
console.info(true || 7)
console.info(7 || true)
```

我们发现，前者得到的结果为true，而后者得到的结果却是7，真是滑天下之大稽，什么鬼玩意，实际上是因为，默认情况下都是true，而后者又是先判断7，因此会直接得到7而不是被转换为true（我们这里可以理解为按顺序阅读）

那么我们再来看看几个特殊值默认代表什么：

```js
console.info(!undefined)
console.info(!null)
console.info(!NaN)
```

最后来使用一下三元运算符，实际上和Java中是一样的：

```js
let a = true ? "xx" : 20
console.info(a)
```

得益于JS的动态类型，三元运算符不一定需要固定的返回值类型。

JS的分支结构，实际上和Java是一样的，也是使用if-else语句来进行：

```js
if("lbwnb"){   //非空串为true
    console.info("!!!")
} else {
    console.info("???")
}
```

同理，多分支语句也能实现：

```js
if(""){
    console.info("!!!")
} else if(-666){
    console.info("???")
} else {
    console.info("O.O")
}
```

当然，多分支语句也可以使用switch来完成：

```js
let a = "a"
switch (a){
    case "a":
        console.info("1")
        break
    case "b":
        console.info("2")
        break
    case "c":
        console.info("3")
        break
    default:
        console.info("4")
}
```

接着我们来看看循环结构，其实循环结构也和Java相差不大：

```js
let i = 10
while(i--){
    console.info("100")
}
```

```js
for (let i = 0; i < 10; i++) {
    console.info("??")
}
```

### JS函数定义

JS中将方法定义为函数，先来看看函数的格式：

```js
function f(){
    console.info("Hello World")
}
```

定义一个函数，，需要在前面加上function关键字表示这是一个函数，调用：

```js
f();
```

我们接着来看，如何给函数添加形式参数以及返回值：

```js
function f(a){
    console.info(a)
    return 666
}

f("aa");
```

由于JS是动态类型，我们不必指明a的类型，同时也不必指明返回值的类型，一个函数可能会返回不同类型的结果，因此我们直接编写return语句即可。同理，我们在调用函数时不传参，那么默认使用undefined：

```js
function f(a){
    console.info(a)
    return 666
}

f();
```

那么，我们如果希望不传参的时候使用我们自定义的默认值呢：

```js
function f(a="1234"){
    console.info(a)
    return 666
}

f();
```

我们可以直接在形参后面定义默认值。

函数本身是一种类型，也可以被变量接收，所有函数类型的变量，也可以被直接调用：

```js
function f(a="1234"){
    console.info(a)
    return 666
}

let k=f;
k();
```

我们也可以直接将匿名函数赋值给变量：

```js
let f=function(str){
    console.info(str)
}
```

既然函数是一种类型，那么函数也能作为一个参数进行传递：

```js
function f(test){
    test();
}

f(function()){
  console.info("这是一个匿名函数);
  }
```

对于所有的匿名函数，可以实现Lambda表达式：

```js
function f(test){
    test();
}

f(()=>{
    console.info("jjj")
})
```

```js
function f(test){
    test();
}

f(param=>{
    console.info(param)
})
```

### JS数组和对象

JS中的数字定义与Java完全不同，数组中的每个元素并不需要是同样的类型：

```js
let arr=[1,"hhh",false,undefined,NaN]
```

我们可以直接通过下标进行访问：

```js
let arr=[1,"hhh",false,undefined,NaN]
console.info(arr[1]);
```

数组还可以动态扩容，如果我们尝试访问超出数组长度的元素，并不会出现错误，而是得到undefined，同样的，我们也可以直接往超出数组长度的地方设置元素：

```js
let arr=[1,"hhh",false,undefined,NaN]
arr[5]="???";
console.info(arr)
```

也可以使用push和pop来实现栈操作：

```js
let arr=[1,"hhh",false,undefined,NaN]
arr.push("bbb")
console.info(arr.pop())
console.info(arr)
```

数组还包括一些其他的方法，这里就不一一列出了：

```js

console.info(arr.map(o=>{
    return 'xxx'+o
}))
```

我们接着来看看对象，JS中也能定义对象，但是这里的对象超出我们的认知：

```js
let obj=new Object()
let obj={}
```

以上两种写法都可以创建对象，但是更推荐下面那种。

JS中的对象也是非常随意的，我们可以动态为其添加属性：

```js
let obj={}

console.info(obj)
```

同理，我们也可以给对象动态添加一个函数：

```js
let obj={}
obj.f=function(){
    console.info("我是对象内部的函数)
}

obj.f()
```

我们可以在函数内使用yhis关键字来指定对象内的属性：

```js
let name="我是外部变量"

注意：如果使用Lambda表达式，那么this并不会指向对象。

除了动态添加属性，我们也可以一开始的时候指定对象内部的成员：

        console.info(this.name)

obj,f()
```

### JS事件

当我们点击一个页面的按钮之后，我们希望之后能够进行登录操作，或是执行一些JS代码来实现某些功能，那么这个时候，就需要用到事件。

事件相当于一个通知，我们可以提前设定好事件发生时需要执行的内容，当事件发生时，会执行我们预先设定好的js代码。

事件有很多类型，其中常用的有：

- onclick：点击事件
- oninput：内容输入事件
- onsubmit：内容提交事件

那么如何为事件添加一个动作呢：

```html
<input type="password" oninput="console.info('正在输入文本...')">
```

我们可以直接为一个元素添加对应事件的属性，比如`oninput`事件，我们可以直接在事件的值中编写js代码，但是注意，只能使用单引号，因为双引号用于囊括整个值。

我们也可以单独写一个函数，当事件发生时直接调用我们的函数：

```js
function f(){
    window.alert("你单独输入了一个字符)
}
```

```html
<input type="password" oninput="oninput()">
```

### Document对象

当网页被加载时，浏览器会创建页面的文档对象模型（Document Object Model），他将整个页面的所有元素映射为JS对象，这样我们就可以在JS中操纵页面中的元素。

比如，我现在想要读取页面中某个输入框中的内容，我们就需要从DOM中获取此输入框元素的对象：

```js
document.getElementById("pwd").value
```

通过document对象就能快速获取当前页面中对应的元素，并且我们也可以快速获取元素中的一些属性。

比如，我们此时进行密码长度的校检，密码长度小于不合法，不合法会让密码边框变红，首先先来编写一个变红的样式：

```css
.illegal-pwd{
    border:red 1px silid !important;
    box-shadow: 0 0 5px red;
}
```

接着，我们编写js代码，定义一个函数，此函数接收一个参数，检测长度是否大于等于6。

```js
function checkIllegal(e){
    if(e.value.length()<6){
        e.setAttribute("class","illegal-pwd")
    }else{
        e.removeArrtibute("class")
    }
}
```

最后，我们将此函数绑定到oninput事件即可，注意传入了一个this，这里的this代表的是输入框元素本身：

```html
<input id="pwd" oninput="checkIllegal(this)" type="password">
```

现在就成功了。

### 发送XHR请求

JS的大致内容我们已经学习完毕，那么如何使用JS与后端进行交互呢：

我们知道，如果我们需要提交表单，那么我们就需要将表单的信息全部发送给我们的服务器，那么，如何发送服务器呢？

通过使用XMLHttpRequest对象，来向服务器发送一个HTTP请求，下面是一个最简单的格式：

```js
let xhr=new XMLHttpRequest();
xhr.open('GET','https//www.baidu.com')
xhr.send();
```

我们像服务器发送了一次网络请求，但是我们请求的是百度服务器，并且请求的方法为GET请求。

我们现在将其绑定到一个按钮上作为事件触发：

```js
function http(){
let xhr=new XMLHttpRequest();
xhr.open('GET','https//www.baidu.com')
xhr.send();
}
```

```html
<input id="button" type="button" onclick="http()">
```

我们可以在网络中查看我们发起的HTTP请求并且查看请求的响应结果，比如上面的请求，会返回百度这个页面的全部HTML代码。

实际上，我们的浏览器在我们输入网址后，也会向对应网站的服务器发起一次HTTP的GET请求。

在浏览器得到页面响应后，会加载当前页面，如果当前页面还引用了其他资源文件，那么会继续向服务器发起请求，直到页面中所有的资源文件全部加载完成后，才会停止。
