# 删除链表的倒数第N个节点
---
## 题目

给你一个链表，删除链表的倒数第 `n` 个结点，并且返回链表的头结点。
**示例 1，*

![](https://assets.leetcode.com/uploads/2020/10/03/remove_ex1.jpg)

**输入:** head = [1,2,3,4,5], n = 2
**输出:** [1,2,3,5]

**示例 2，*

**输入:** head = [1], n = 1
**输出:** []

**示例 3，*

**输入:** head = [1,2], n = 1
**输出:** [1]

---
## 思路

1. 老样子，先判空。2. 添加虚拟头节点，防止第一个元素是目标节点。3. 然后看这道题，这道题要求删除倒数第 n 个节点，那么我们需要先进行遍历，计算出链表节点的数量，然后才能推出倒数第 n 个节点所在的位置，`要走的步数 = 总长度 - n`。4. 比如，5 个节点，我要删除倒数第二个节点，总长度为 5，n = 2，要走的步数 = 3；然后我们从虚拟头节点开始走起，此时走到以后，我们发现我们的下一个节点就是目标节点。5. 此时，我们进阶的思路是快慢指针，让快指针先走 n+1 步，然后二者同时前进，当快指针走到 null（尾节点的下一个节点），那么此时，慢指针刚好在目标节点的前一个节点。6. 原理：当到达目标节点的前一个节点时，快指针的位置 - 慢指针的位置 =（n+1）## 解答

```Java
class Solution {

    public ListNode removeNthFromEnd(ListNode head, int n) {

        if(head==null) return null;

  

        ListNode VHead=new ListNode();

        VHead.next=head;

  

        ListNode slow=VHead;

        ListNode fast=VHead;

  

        for(int i=0;i<n+1;i++){

            fast=fast.next;

        }

  

        while(fast!=null){

            fast=fast.next;

            slow=slow.next;

        }

        slow.next=slow.next.next;

        return VHead.next;

    }

}
```
