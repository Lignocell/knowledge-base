# 有效的括号
## 题目

给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s` ，判断字符串是否有效。
有效字符串需满足：
1. 左括号必须用相同类型的右括号闭合。2. 左括号必须以正确的顺序闭合。3. 每个右括号都有一个对应的相同类型的左括号。
**示例 1，*

**输入:** s = "()"

**输出:** true

**示例 2，*

**输入:** s = "()[]{}"

**输出:** true

**示例 3，*

**输入:** s = "(]"

**输出:** false

**示例 4，*

**输入:** s = "([])"

**输出:** true

**示例 5，*

**输入:** s = "([)]"

**输出:** false

---
## 思路

1. 老样子，先判空。2. 这道题，拿到就有思路了，使用栈来进行括号匹配。3. 如果是左边括号，就压入栈中，如果是右边，则和栈顶元素进行比较，如果二者同一类型，则删除栈顶元素，如果不同，则返回 false。## 解答

```Java
class Solution {

    public boolean isValid(String s) {

        if (s == null)

            return false;

        Stack<Character> stack = new Stack<>();

  

        for(int i=0;i<s.length();i++){

            char ss=s.charAt(i);

            if(ss=='('||ss=='['||ss=='{'){

                stack.push(ss);

            }else{

                if(stack.isEmpty()) return false;

                char top = stack.peek();

                if( (ss == ')' && top == '(') ||

                    (ss == ']' && top == '[') ||

                    (ss == '}' && top == '{') ){

                    stack.pop();

                }else{

                    return false;

                }

            }

        }

            return stack.isEmpty();

    }

  

}
```
