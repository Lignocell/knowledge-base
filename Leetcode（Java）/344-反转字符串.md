# 反转字符串
## 题目

编写一个函数，其作用是将输入的字符串反转过来。输入字符串以字符数组 `s` 的形式给出。
不要给另外的数组分配额外的空间，你必须* [原地](https://baike.baidu.com/item/%E5%8E%9F%E5%9C%B0%E7%AE%97%E6%B3%95)修改输入数组**、使用 O(1) 的额外空间解决这一问题。
**示例 1，*

**输入:** s = ["h","e","l","l","o"]
**输出:** ["o","l","l","e","h"]

**示例 2，*

**输入:** s = ["H","a","n","n","a","h"]
**输出:** ["h","a","n","n","a","H"]

---
## 思路

1. 这道题不用判空。2. 我们可以直接明确思路，定义双指针，指向头尾两端。3. 然后让指针交换，然后想内移动，直到二者指向同一字符。## 解答

```Java
class Solution {

    public void reverseString(char[] s) {

        int left = 0;

        int right = s.length - 1;

  

        while (left < right) {

            char temp = s[right];

            s[right] = s[left];

            s[left] = temp;

            left++;

            right--;

        }

    }

}
```
