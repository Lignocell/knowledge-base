# 移除链表元素

---
## 题目

给你一个链表的头节点 `head` 和一个整数 `val` ，请你删除链表中所有满足 `Node.val == val` 的节点，并返回 **新的头节点* 。
**示例 1，*

![](https://assets.leetcode.com/uploads/2021/03/06/removelinked-list.jpg)

**输入:** head = [1,2,6,3,4,5,6], val = 6
**输出:** [1,2,3,4,5]

**示例 2，*

**输入:** head = [], val = 1
**输出:** []

**示例 3，*

**输入:** head = [7,7,7,7], val = 7
**输出:** []

---
## 思路

1. 老样子，先判空。2. 接下来，我们看题目，本题要求移除目标元素，那么就涉及到了链表的删除操作。
   链表删除，需要目标节点的前一个节点的下一个节点指向目标节点的下一个节点造成删除(`pre.next=cur.next`)。3. 那么，我们从第一个开始，此时我们要想到，如果 val 在第一个节点也有怎么办，这里我们用到了虚拟头节点，也就是说，定义一个虚拟的头节点，这样如果第一个节点也是目标节点（或者只有 head 只有一个节点），那么虚拟头节点就发挥了用处。## 解答

```Java
class Solution {

    public ListNode removeElements(ListNode head, int val) {

        if (head == null)

            return null;

  

        ListNode VHead = new ListNode();

        VHead.next = head;

  

        ListNode cur = head;

        ListNode pre = VHead;

  

        while (cur != null) {

            if (cur.val == val) {

                pre.next = cur.next;

                cur = cur.next;

            } else {

                cur = cur.next;

                pre = pre.next;

            }

        }

        return VHead.next;

    }

}
```
