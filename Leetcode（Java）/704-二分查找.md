# 二分查找

---
## 题目

给定一个 `n` 个元素有序的（升序）整型数组 `nums` 和一个目标值 `target`  ，写一个函数搜索 `nums` 中的 `target`，如果 `target` 存在返回下标，否则返回 `-1`。
你必须编写一个具有 `O(log n)` 时间复杂度的算法。
  
**示例 1:**

**输入:** `nums` = [-1,0,3,5,9,12], `target` = 9
**输出:** 4
**解释:** 9 出现在`nums` 中并且下标为 4

**示例 2:**

**输入:** `nums` = [-1,0,3,5,9,12], `target` = 2
**输出:** -1
**解释:** 2 不存在`nums` 中因此返回-1

---

## 思路

1. 和普通题目一样，先判空，即`if(nums==null||nums.length==0) return -1`。2. 看到题目，我的第一个想法就是遍历数组。```Java
   class Solution {

    public int search(int[] nums, int target) {

        if (nums == null || nums.length == 0)

            return -1;

        for (int i = 0; i < nums.length; i++) {

            if (target == nums[i]) {

                return i;

            }

        }

        return -1;

    }

}
```
看起来没什么问题，但是这道题的目的是二分查找，且直接枚举的时间复杂度是O(n)。3. 那么我们来思考二分查找，二分查找有两个特征，根据特征来选取思路。   - 有序数组。   - 找目标值。4. 所谓二分查找，其实就是定义一个左指针和一个右指针，二者相加之和取中间值，然后让中间值和目标值进行比较，如果中间值小，那么让左指针向右移动（提高中间值的大小）；同理，如果中间值大，那么让右指针向左移动。这样来选取到目标值。## 解答

```Java
class Solution {

    public int search(int[] nums, int target) {

        if (nums == null || nums.length == 0)

            return -1;

  

        int left = 0;

        int right = nums.length - 1;

  

        while (left <= right) {

            int mid = left + (right - left) / 2;
            //这里是防止栈溢出（即Integer.MAX_VALUE = 2147483647）
            if (target < nums[mid])

                right = mid - 1;

            else if (target > nums[mid])

                left = mid + 1;

            else

                return mid;

        }

        return -1;

    }

}
```
