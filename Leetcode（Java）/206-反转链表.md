# 反转链表

---
## 题目

给你单链表的头节点 `head` ，请你反转链表，并返回反转后的链表。
**示例 1，*

![](https://assets.leetcode.com/uploads/2021/02/19/rev1ex1.jpg)

**输入:** head = [1,2,3,4,5]
**输出:** [5,4,3,2,1]

**示例 2，*

![](https://assets.leetcode.com/uploads/2021/02/19/rev1ex2.jpg)

**输入:** head = [1,2]
**输出:** [2,1]

**示例 3，*

**输入:** head = []
**输出:** []

---
## 思路

1. 老样子，先判空。2. 想要反转链表，我们的第一个想法，肯定是将箭头指向进行反转。3. 那么我们先看头节点，我们需要将头节点变为尾节点，那么箭头指向先指向空。4. 然后我们还需要注意，我们需要定义一个指针`temp` 指向还未反转的链表，因为一旦反转中节点的指向断掉，如果不保存，那么就会发生遗失。5. 我们还需要定义两个指针，一个是指向当前节点`cur`，一个指向当前值的前一个节点`pre`。6. 如果不定义`cur` 那么使用 head 则会让链表起点直接丢失。7. `pre` 当第一个循环结束后，将 pre 往后移动一个，指向 cur 所在的节点，cur 向后循环。8. 流程：cur 指向当前节点，pre 指向空，temp 同理，先让 temp 指向 cur 的下一个节点；
   然后 cur 的下一节点指向 pre（反转当前节点）；接着，pre 向前移动，cur 也要向前（准备第二节点的反转）。
## 解答

```Java
class Solution {

    public ListNode reverseList(ListNode head) {

        if (head == null || head.next == null)

            return head;

  

        ListNode temp = null;

        ListNode cur = head;

        ListNode pre = null;

        while (cur != null) {

            temp = cur.next;

            cur.next = pre;

            pre = cur;

            cur = temp;

        }

        return pre;

    }

}
```
