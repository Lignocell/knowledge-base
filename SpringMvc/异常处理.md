# 异常处理

当我们的请求映射方法出现异常时，会直接展示到前端页面，这是因为SpringMVC为我们提供了默认的异常处理界面，当出现异常时，我们的请求会自动转交给专门用于异常处理的控制器中进行处理。

当然，我们也可以自定义一个异常处理控制器，一旦出现指定异常，就会转交给此控制器中进行：

```java
@ControllerAdvice
public class ErrorController {

    @ExceptionHandler(Exception.class)
    public String error(Exception e, Model model){  //可以直接添加形参来获取异常
        e.printStackTrace();
        model.addAttribute("e", e);
        return "500";
    }
}
```

接着，我们编写一个专门显示异常的界面：

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Title</title>
</head>
<body>
  500 - 服务器出现了一个内部错误QAQ
  <div th:text="${e}"></div>
</body>
</html>
```

接着修改：

```java
@RequestMapping("/index")
public String index(){
    System.out.println("我是处理，);
    if(true) throw new RuntimeException("您的氪金力度不足，无法访问！");
    return "index";
}
```

访问后，我们发现控制台会输出异常信息，同时页面也是我们自定义的一个页面。
