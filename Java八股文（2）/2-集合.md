## 模块一：集合体系与遍历

#### Q1：【S】常用的集合分类以及它们的区别？ 👑

- 分为Map和Collection两大类。
- Collection：
	- List：强调有序可重复，可通过索引访问。
	- Set：强调无序不可重复，通过HashCode和equals去重。
	- Queue：队列先进先出。
- Map：
	- HashMap：无序，强调键唯一。
	- LinkedHashMap：保持插入顺序。
	- TreeMap：按键排序，同键会覆盖重复值。

#### Q4：【S】什么是 fail-fast，什么是 fail-safe？ 👑

- fail-fast：适用于ArrayList、HashMap；内部维护一个修改计数器，开始前记录预期计数，迭代途中验证计数，当发生错误时，立刻抛出异常，终止迭代。
- fail-safe：适用于CopyOnWriteArrayList、ConcurrentHashMap；迭代开始前对原数据进行快照，迭代快照，保证线程安全，但是损失一定的时效性。

## 模块二：List 与 Set

#### Q5：【S】讲一下 Java 里面 List 的几种实现类？ 👑

- ArrayList：底层基于动态数组，适用于读多写少场景。
- LinkedList：底层基于双向链表，善于增删元素，适用于写多读少场景。
- ~~Vector：底层基于动态数组，但是所以操作加锁，线程安全，但性能差，少用。~~
- CopyOnWriteArrayList：线程安全，修改时复制数组，适用于读多写少的并发场景。

#### Q6：【S】展开讲讲 ArrayList 👑

- 底层基于动态数组，默认长度为10，装满后会按1.5倍扩容。
- 扩容采用新建数组，然后将原数组复制粘贴，因此写效率较慢，且线程不安全。
- 由于数组索引机制，因此适用于读多场景。

#### Q8：【S】聊聊你对 HashSet 的理解 👑

- HashSet底层是HashMap的轻量封装，底层是将元素作为HashMap的key，value一般是空对象或者占位符。
- 通过HashCode()计算哈希值存储，通过equals()比较去重。
- 适用于无需顺序的高效去重场景。
- 需要维护插入顺序选择LinkedHashSet，需要排序选择TreeSet。
