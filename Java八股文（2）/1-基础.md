#### Q3：【S】JVM、JDK、JRE 三者的区别是什么？ 👑

- JVM是Java虚拟机，是Java跨平台的核心。（跨平台基础）
- JRE是Java运行时环境，包括JVM和Java运行的核心类库。（用于运行）
- JDK包含了JVM，JRE以及Java的开发工具包，还附带编译器和各种调试工具，是开发Java的完整环境。（用于开发）

#### Q4：【A】Java 是如何实现跨平台的？

- Java通过字节码+JVM实现跨平台。
- 源码被编译成与平台无关的字节码，然后再由不同操作系统上的JVM将字节码解释为机器码运行，

#### Q5：【A】什么是字节码？采用字节码的好处是什么？

- 字节码是JVM可以理解执行的指令，JVM会将Java代码转换成.class文件。
- 字节码的识别不靠软硬件，只靠计算机上的JVM环境，因此能够实现**一次编译，到处运行**。
- JVM会对字节码进行安全性验证，因此安全性更高。
- JVM采用JIT（即时编译技术），同时字节码比源代码更紧凑，因此执行效率更高。

#### Q6：【A】为什么说 Java 语言编译与解释并存？

- Java语言会被javac编译器编译为字节码文件。
- JVM会将字节码文件解释为机器码来运行。

#### Q14：【S】为什么浮点数运算的时候会有精度丢失的风险？如何解决？ 👑⭐

- 计算机通常是用二进制来存储浮点数，大多数十进制小数转换成二进制时无法做到精确转换，因此误差会累积放大。
- 使用BigDecimal替代浮点数，适合银行或者化工等敏感数行业。

#### Q15：【S】基本类型和包装类型的区别？ 👑

- 基本类型保存的是数字本身，轻量高效，用于数学的计算。

- 包装类型则是对基本类型的封装，被用于参与泛型和集合类的计算。

	**注意：**缓存池陷阱：Integer在-128~127之间使用`==`是相等的，超出后必须使用`.equals()`。


#### Q16：【S】自动装箱与拆箱了解吗？原理是什么？ 👑

- 自动装箱是将基本类型转化为封装类型，自动拆箱反之。
- Java在底层调用封装类的`valueOf()`将基本类型转换成封装类型，反之使用`xxxValue()`。

#### Q26：【S】面向对象三大特征 👑

- 封装：对实现细节进行隐藏，仅提供有限接口。
- 继承：子承父业，提高代码的复用性。
- 多态：一个接口，多种实现（重写/接口）。

#### Q27：【S】接口和抽象类有什么共同点和区别？ 👑

- 相同点：都是抽象类型，都无法直接实例化，都可以定义规范。
- 不同点：
	- 抽象类：侧重于单继承，即父与子的关系。
	- 接口：侧重于多实现，即多个实现方法。
