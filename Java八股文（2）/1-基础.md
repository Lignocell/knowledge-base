#### Q3：【S】JVM、JDK、JRE 三者的区别是什么？ 👑

- JVM是Java虚拟机，是Java跨平台的核心。（跨平台基础）
- JRE是Java运行时环境，包括JVM和Java运行的核心类库。（用于运行）
- JDK包含了JVM，JRE以及Java的开发工具包，还附带编译器和各种调试工具，是开发Java的完整环境。（用于开发）

#### Q4：【A】Java 是如何实现跨平台的？

- Java通过字节码+JVM实现跨平台。
- 源码被编译成与平台无关的字节码，然后再由不同操作系统上的JVM将字节码解释为机器码运行，

#### Q5：【A】什么是字节码？采用字节码的好处是什么？

- 字节码是JVM可以理解执行的指令，JVM会将Java代码转换成.class文件。
- 字节码的识别不靠软硬件，只靠计算机上的JVM环境，因此能够实现**一次编译，到处运行**。
- JVM会对字节码进行安全性验证，因此安全性更高。
- JVM采用JIT（即时编译技术），同时字节码比源代码更紧凑，因此执行效率更高。

#### Q6：【A】为什么说 Java 语言编译与解释并存？

- Java语言会被javac编译器编译为字节码文件。
- JVM会将字节码文件解释为机器码来运行。

## 模块四：对象相等与拷贝



#### Q36：【S】对象的相等和引用相等的区别 👑

- 对象相等指的是二者的值是否相等（`equals()`）。
- 引用相等则指向的是二者是否是同一对象（`==`）。

#### Q37：【S】String#equals() 和 Object#equals() 有何区别？ 👑

- Object比较的是二者是否是同一对象，即引用相等。
- String重写了Object的方法，比较的是二者的值，即对字符串进行比较。


#### Q38：【S】为什么要有 hashCode？ 👑

- hashCode是Object的默认方法，所有的Java类默认继承。
- 通过hashCode，可以通过哈希值预定位来减少equals()集合类的比较次数。


#### Q39：【S】为什么重写 equals() 时必须重写 hashCode()？ 👑⭐

- 如果不重写，则会导致逻辑相同的对象哈希编码不同，会在哈希桶中无法正确检索。

#### Q40：【A】什么是引用拷贝、深拷贝、浅拷贝？它们的区别了解吗？ 👑⭐

- 引用拷贝拷贝的是对象所在地址，修改副本会影响原本的地址。
- 浅拷贝拷贝的对象本身以及基本类型，不会拷贝引用类型，修改副本同样会影响原本。
- 深拷贝是拷贝对象的所有数据，与原本相互隔离，修改副本对原本不会有影响。

## 模块五：String 家族与字符串常量池



#### Q41：【B】字符型常量和字符串常量的区别？




#### Q42：【S】String 为什么是不可变的？ 👑

- String不可变，可以让多线程操纵同一String类天然安全。
- 可以保证字符串常量池不会改变。
- 保证哈希表的键安全性，防止因String改变操纵哈希存储偏移。
- 保证密码安全性，包括但不限于各类账户密码，URL等等。


#### Q43：【S】String、StringBuffer、StringBuilder 有何区别？ 👑

- String不可变，因此每次修改都是创建一个新的String。
- StringBuffer是线程安全的可变字符串，操纵StringBuffer时会存在锁机制保证线程安全，因此开销较大，性能较低。
- StringBuilder线程不安全，但是性能较高。

#### Q44：【S】字符串常量池的作用了解吗？ 👑

- 字符串常量池是JVM专门在内存中创建的存储字符串常量的区域，可避免重复创建相同字符串，提高内存利用率。


#### Q45：【A】intern 方法有什么作用？ 👑⭐




#### Q46：【S】字符串拼接使用 `+` 还是 StringBuilder 更好？ 👑

- 小范围拼接使用`+`，编译时编译器会自动转化成append()进行拼接。
- 大范围、循环则使用StringBuilder或StringBuffer，如果使用`+`，那么编译器会循环创建出若干个StringBuilder实例。


#### Q47：【S】String 类型的变量和常量做 `+` 运算时发生了什么？ 👑⭐

- 如果全为常量时，编译器会优先计算出结果并存入常量池。
- 如果存在变量，那么会在编译时转换为`StringBuilder.append()`进行拼接。
- 如果final修饰了变量，当该变量在编译期内可以确定值，那么就同样以常量拼接方式运算；反之，仍是照常拼接。

#### Q48：【S】`String s1 = new String("abc");` 创建了几个对象？ 👑⭐

- 若字符串常量池中存在abc，则只创建了一个String实例。
- 若不存在，则创建了两个。

## 模块六：异常机制



#### Q49：【S】聊聊 Java 的异常体系？ 👑

- Java异常体系是以Throwable为根类，分为Error和Exception两类。
- Error：系统级异常，由JVM抛出，无法处理。
- Exception：程序可处理的异常，分为受检异常与非受检异常。
	- 受检异常：在编译器报错，必须由try-catch处理，或用throws抛出。
	- 非受检异常：由逻辑错误引起，不强制处理。

#### Q50：【S】Error 和 Exception 的区别？ 👑

- Error：系统级问题，无法被被处理的严重错误，如栈溢出，内存溢出。
- Exception：业务级可处理的问题，可以由业务代码捕获并抛出异常，如空指针等。
