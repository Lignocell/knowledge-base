# 263.火车进站

---

## 一、题目

 有 *n* 列火车按 1 到 *n* 的顺序从东方左转进站，这个车站是南北方向的，它虽然无限长，只可惜是一个死胡同，而且站台只有一条股道，火车只能倒着从西方出去，而且每列火车必须进站，先进后出。

 进站的火车编号顺序为 1 到 *n*，现在请你按火车编号从小到大的顺序，输出20 种可能的出站方案。

------

#### 输入

 输入一行一个整数 *n*。（*n* ≥ 0）

#### 输出

 输出最多 20 种答案，每行一种，不要空格。

------

#### 样例输入1

```
3
```

#### 样例输出1

```
123
132
213
231
321
```

#### 样例输入2

```
4
```

#### 样例输出2

```
1234
1243
1324
1342
1432
2134
2143
2314
2341
2431
3214
3241
3421
4321
```

------

#### 数据规模与约束

 时间限制， s

 内存限制，56 M

 100% 的数据保证 *n* ≥ 0

## 二、解析

### 思路

本题火车进站其实就是进“栈”，火车进入栈时只能按照从前往后的顺序进入栈中。

样例一中，输出的结果缺少312，由于火车是按顺序入栈，3出栈后，由于栈顶1、2被压在栈底，此时要想按照312的顺序出栈，显然是不可能的，所以312非法，这便是题目的意思。

### 代码

```cpp
#include<stack>
#include<iostream>
#include<algorithm>
using namespace std;

bool isvail(int a[],int n)//用来判断序列是不是合法
{
    stack<int>s;
    int x=1;//用x模拟数组元素
    for(int i=0;i<n;i++)
    {
        if(!s.empty() || s.top()<a[i])//当a[i]比栈顶元素小，那么a[i]此时便是在栈底，那么该序列就是非法序列
        {
            while(x<=a[i])
            {
                s.push(x);
                x++;
            }         
        }
        //此时，栈顶元素应该与a[i]相同，因此再次加上判断。
        if(s.empty() || s.top()!=a[i]) return false;
        s.pop();
    }
    return true;
}


int main()
{
    int n=0,a[25];
    int cnt=20;//题目要求最多输出 20 组，用cnt进行计数
    cin>>n;//输入火车的节数
    
    for(int i=0;i<n;i++) a[i]=i+1;//将a数组进行赋值
    
    //进行全排列的枚举
    do
    {
        while(isvail(a,n))//判断数组中的数字排列后是否是非法序列
        {
            for(int i=0;i<n;i++)
            {
                cout<<a[i];
                cnt--;
            }
            cout<<endl;
        }
    }
    while(next_permutation(a,a+n) && cnt);//next_permutation是c++的一个库函数，用来进行全排列，第一个要求传入数组名，第                                             二个要求传入元素的尾地址
    return 0;
}
```
