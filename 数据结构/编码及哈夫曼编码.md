# 编码

---

## 一、编码的概念

编码是将信息（如字符）转换为特定格式的过程，以便于存储、处理和传输。字符编码的主要目的是使机器能够理解和处理文本数据。

即本质上，数据通过编码进行传输，进而影响传输速率。

## 二、变长编码与定长编码

##### 区别：

每种字符的编码长度是否一样（26个字母相当于26个字符）

##### 变长编码的优点：

一篇文章中，出现的字母如果频率越高，那么，该字符的编码长度越短，传输速率越快，进而使得总传输速率比定长编码快。

## 三、平均编码长度

计算平均编码长度实际上其实是计算在同样的速度下，哪种编码效率最高。

可以类比==数学期望的计算==。

即`编码长度*出现概率`。

## 四、最优的变长编码：哈夫曼编码

#### 哈夫曼编码的生成过程：

1. 首先，计算得到每一种字符的概率。
2. 然后，每次将最低概率的两个节点*合并*成为一棵子树。
3. 经过n-1轮合并，形成一棵哈夫曼树（本质上是一种二叉树）。
4. 按照左0，右1的方式，将编码进行读取。（从根节点进行从上往下的读取）

#### 两个字符的编码之间不能形成前缀关系：

比如：

a:1
b:10
c:0

当编码的结果为10时，有可能源代码是ab，也有可能是aac。

#### 代码演示

建立哈夫曼树时，先按照上面的顺序找到两个最低概率的字符，将他们放到数组的最后两个位置

```cpp
//定义结构体类型
typedef struct node
{
    char ch;
    int freq;//频次，即字符出现的概率
    struct node * left, * right;
}node;

//包装节点
node* getnewnode(int freq,char ch)
{
    node* p = (node*)malloc(sizeof(node));
    p->ch = ch;
    p->freq = freq;
    p->left = p->right = NULL;
    return p;
}

//交换代码
void swap_node(node** node_arr, int i, int j)
{
    node* temp = node_arr[i];
    node_arr[i] = node_arr[j];
    node_arr[j] = temp;
}

//寻找最小字符的代码
int find_min_node(node** node_arr, int n)
{
   
    int temp = 0;
    for (int j = 0; j < n ; j++)
    {
        if (node_arr[temp]->freq > node_arr[j]->freq) temp = j;
    }
    return temp;
}

//形成哈夫曼树的主代码
node* buildtree(node** node_arr, int n)
{
    for (int i = 1; i < n; i++)//首先，进行n-1次的合并
    {
        //找到最小概率的两个节点
        int ind = find_min_node(node_arr, n-i);//n-i表示最后一个节点
        swap_node(node_arr, ind, n - i);//将最小概率的那个节点与最后一位进行交换
        
        int ind2 = find_min_node(node_arr, n - i - 1);
        swap_node(node_arr, ind2, n - i - 1);//将第二个最小概率的节点与倒数第二位互换
        
        int freq = node_arr[n - i]->freq + node_arr[n - i - 1];
        node* node = getnewnode(freq, 0);//将两个节点合成一个树，并包装成节点
        //再形成哈夫曼树的过程中，除了叶子节点，其他任何节点都不具有实际意义，所有为0
        node->left = node_arr[n - i - 1];
        node->right = node_arr[n - i];
        node_arr[n - i - 1] = node;//哈夫曼树形成以后，将这个新的节点放回到原数组的倒数第二位。
   }
    return node_arr[0];//返回哈夫曼树的根节点
}
```

最后遍历哈夫曼树并输出每个字符的哈夫曼编码。

```cpp
void deliver(node*root,char buff[], int k)
//buff 是一个字符数组，用于存储当前路径的编码（0 表示左子树，1 表示右子树）。
//k 是当前编码的深度（即数组的索引）。
{
    buff[k] = 0;//初始化
    if (root->left == NULL && root->right == NULL)//如果当前节点是叶子节点
    {
        printf("%c:%s\n", root->ch, buff);
        return;
    }
    //如果不是叶子节点，进行递归
    buff[k] = '0';//将左子树设置为
    deliver(root->left, buff, k + 1);
    buff[k] = '1';//将右子树设置为
    deliver(root->right, buff, k + 1);
    return;
}
```
