# 时间复杂度与空间复杂度

---

## 一、理解

时间复杂度：马跑的速度

空间复杂度：马吃草的多少

+ 时间复杂度与空间复杂度都是衡量一个程序的好坏，程序运行效率越高，时间复杂度越快；程序所占用的字节越少，空间复杂度越小。
+ 一般二者无法同时缩小或者增大，要么以空间换取时间，要么以时间换取空间。

## 二、步骤

### 大O的渐进表示法：（时间复杂度与空间复杂度同理）

+ 用常数取代运行时间内的所有加法常数（即所有加的常数都改成1）

+ 在修改后的运行次数函数中，只保留最高阶项（即所有函数只保留最高次幂）
+ 如果最高阶项存在且不是1，则去除与这个项目相乘的常数（即最高次幂的项数化简即可）

#### ==口诀：系数归一，常数归一，保留最高次幂==

## 三、计算

### 1. 时间复杂度

####    常数项

```c
for(int i=0;i<100;i++)
{
    //...
}
```

此时该函数循环了100次，与n无关，100是常数，常数归一，时间复杂度为*O(1)**。

####  线性栈

```c
for(int i=0;i<n;i++)
{
  //...
}
```

此时，该循环循环了n次，与n相关，系数为一，保留最高次，时间复杂度为*O(n)**。

```c
for(int i=0;i<n;i+=2)
{
  //...
}
```

此时，该循环循环了n次，与n相关，系数为1/2，保留最高次，系数归一，时间复杂度为*O(n)**。

#### 对数复杂度

```c
for(int i=0;i<n;i*=2)
{
//...
}
```

此时，该循环虽然循环了n次，2^x^=n,得到log~2~(n),此时会把2进行省略，此时时间复杂度为*O(logn)**。

#### 平方复杂度

```c
for(int i=0;i<n;i++)
{
 for(int j=0;j<n;j++)
 {
   //...
 }
}
```

此时，该函数循环了n*m次，即时间复杂度为*O(nm)**。

#### 根号复杂度

```c
for(int i=0;i*i<n;i++)
{
//...
}
```

此时，时间复杂度为*O($\sqrt{n}$)**。

### 2. 空间复杂度

+ 空间复杂度计算的是程序中申请变量的个数，采用大O的渐进表示法。

- 空间反复使用时不会进行累积。

- 形参也可以算，在函数中开辟空间。

+ 数组传参时，传入的是首元素的地址，即是一个指针，空间复杂度算法
+ malloc等开辟空间时，同样也参与计算。
+ 递归调用时，每次调用建立一个栈帧，每个栈帧使用了常数个空间，再乘上传入的形参。
