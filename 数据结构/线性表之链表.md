# 线性表之链表

## 一、总讲解

+ 链表在空间上并不连续，每个节点都含有一个数据和一个地址，每个地址指向下一个节点，构成一条链表。

+ 解决顺序表从中间插入的效率低的问题。

## 二、分类

链表分为无头链表和有头链表。

- 无头链表， 头部不存储信息，只含有指向下一节点的首地址。
- 有头链表：头部存储链表的第一个信息（虚拟头节点）。

## 三、循环链表（分类及特点）

+ 单向循环链表中，最后一个节点指向第一个节点，也就是说，最后一个节点储存的地址是第一个节点的位置。
  这一特点使得向一号节点的前面插入时不需要遍历所有的链表节点。

+ 双向循环链表中，每一个节点都包含一份数据和两个指针，其中首尾两个节点中，各有一个指针指向NULL。



## 四、插入节点

### 定义：

插入节点时不能直接插入，需要先让一个新的指针p指向待插入位置的==前一个元素=，*<u>p用来防止前一个节点丢失</u>**），让新的节点指向待插入位置的后一个元素，再让前一个节点的指针指向新的节点。

   有初始化就有删除

   以下是销毁链表的操作

   ```c
   void clear(node*head)//head指链表的首地址（不需要链表本身）
   {
       if(head==NULL) return;
       else
       {
           for(node*p=head,*q;p;q=p)//不能直接销毁p,直接销毁当前节点会使得无法找到下一个节点
           //需要借助另一个变量，不断的循环，让q与p的下一个节点的地址相同
           {
               q=p->next;
               free(p);
           }
       }
   }
   ```

   插入操作(一)

   ```c
   node*insert(node*head,int pos,int val)
       //     主体的首地址  插入位置  插入的参数
   {
       if（pos==0)//插入位置是第一位
       {
          node*p=GetNewNode(val);//先将val这个值做成一个新的节点
           p->next=head;//让val所代表的节点成为这个链表的首地址
           return p;
       }
       else
       {
           node*p=head;
           for(int i=1;i<pos;i++)p=p->next;//找到待插入位置的前一个元素
           
           node*node=GetNewNode(val);//同理，先将val这个值做成一个新的节点
           node->next=p->next;//让新的节点指向待插入位置的后一个元素
           p->next=node;//让前一个节点的指针指向新的节点
           return head;
       }    
   }
   ```

   插入操作（(==有头链表：即定义一个虚拟头节点==)

   ```c
   node *insert(node*head,int pos,int val)
   {
       node new_head,*p=&new_head,*node GetNewNode(val);
       //    虚拟头节点  p是虚拟头节点的首地址   val进行节点的包装
       new_head.next=head;//将虚拟头节点插入链表，成为真正的头节点
       for(inti=0;i<pos;i++) p=p->next;//遍历链表，让p移动到待插入位置的前一个节点

       p->next=node;//进行插入操作，不是替代下一个，而是插入
   }
   ```
