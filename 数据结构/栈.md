# 栈

---

## 一、含义

只允许在一头进行插入与删除操作的线性表。

## 二、属性

只包括连个指针，分别是top与size。

top:只指向头节点，如果栈内没有元素，**则tail指向-1**。

size:表示栈的大小。

## 三、特点

- 只允许在头部进行入栈和出栈（先进后出）。
- 入栈时让栈顶指针向上移动一位，并让元素进入(push)。
- 出栈时只需要让栈顶指针向下移动一下（pop)。

## 四、代码操作

### typedef(结构体

```cpp
typedef struct stack
{
    stack *data;
    int top,size;
}stack;
```



### initstack(初始化栈)

```cpp
stack *initstack (int n)
{
    stack *s=(sttack*)malloc(sizeof(stack));//为栈的结构体分配内存
    s->data=(int *)malloc(sizeof(int)*n);//为栈的数据区分配内存
    s->data=n;//将数据区以n为大小
    s->top=-1;//初始化栈为空
    return s;
}
```

### empty(栈判断

```cpp
int empty(stack *s)
{
    return s->top=-1;
}
```

### top(查看栈顶元素)

```cpp
int top(stack *s)
{
    if(empty(s)) return 0;
    return s->data[s->top];//返回top所指向的元素的值
}
```

### push（入栈）

```cpp
int push(stack*s,int val)
{
    if(s->top+1==s->size) return 0;//判断栈是否是满的
    s->top++;
    s->data[s->top]=val;
    return 1;
}
```

### pop(出栈)

```cpp
int pop(stack*s)
{
    if(empty(s)) return 0;//判断栈中是否为空
    s->top--;
    return 1;
}
```

clear(清空栈

```cpp
void clearstack(stack *s)
{
    if(s==NULL) return ;
    free(s->data);//先回收s的存储区
    free(s);//再回收栈本身
}
```
