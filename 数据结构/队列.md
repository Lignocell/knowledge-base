# 队列

---

## 一、定义

是一段连续的存储区域。（不重要）

## 二、特性

- 只能从尾部插入，只能从头部删除。先进先出)(可以比喻售票时的排队)

- 相较于顺序表与链表来说，是较为高级的数据结构。

- 队列的尾指针tail)指向的是空地址，即没有元素，是左闭右开区间。

## 三、属性

size:队列大小。
count:队列的元素个数。
head:队列的头部。
tail:  队列的尾部。
push:尾部的插入操作。
pop:  头部的删除操作

## 四、封装

- 可以使用顺序表或者链表对队列进行封装，即以较低级的数据结构为底层逻辑，为较高级的数据结构进行封装。
-  由于链表是通过指针进行链接，那么通过链表进行封装队列时，可以不考虑存储空间的大小，也不存在假溢出的问题；也不需要头尾指针了

## 五、循环队列

### 特点

- 与普通队列相比，由于执行删除操作时会从头开始删除元素，造成队列中空间的浪费；执行循环队列的插入操作时，如果tail结尾处的空间不够而越界)，可以让tail指向0号节点，进行空间的循环，以免造成空间浪费。
- 通过链表进行封装队列时，不需要考虑循环队列。

## 六、代码

### 1. 顺序表封装

### 顺序表部分：

#### typederf(结构体

```cpp
typedef struct vector
{
    int *data;
    int size;
}vector;
```

#### initvector(初始化

```cpp
vector *initvector(int n)
{
    vector *v=(vector*)malloc(sizeof(vector));//为顺序表的结构体开辟存储空间
    v->data=(int *)malloc(sizeof(int)*n);//为顺序表的数据区开辟存储空间
    v->size=n;
    return v;
}
```

#### clear(清除)

```cpp
void clearvector(vector *v)
{
    if(v==NULL) return;
    free(v->data);//先回收数据区
    free(v);//再回收顺序表本身
}
```

#### seek(查看某个节点

```cpp
int seekvector(vector *v,int pos)
{
    if(pos<0||pos>=v->size) return -1;//如果位置不合法，拒绝实行这个操作
    return v->data[pos];
}
```

#### insert(插入)

```cpp
int insertvector(vector *v,int pos,int val)//本质上不是插入，而是把某个值改写成val
{
    if(pos<0||pos>=v->size) return 0;
    v->data[pos]=val;
    return 1;
}
```



### 队列部分：

#### typedef(结构体)

```cpp
typedef struct queue
{
    vector*data;
    int size,head,tail,count;
}queue;
```

#### initqueue(初始化

```cpp
queue *initqueue(int n)
{
    queue *q=(queue*)malloc(sizeof(queue));//为队列的结构体分配内存
    q->data=initvector(n);//初始化一个大小为n的顺序表，为队列的数据区分配内存
    q->size=n;
    q->head=q->tail=q->count;//队列为空
    return q;
}
```

#### empty(判空)

```cpp
int empty(queue*q)
{  
    return q->count==0;
}
```

#### front(查看队首元素)

```cpp
int front(queue *q)
{
    return vectorseek(q->data,q->head);
}
```

#### push(插入)

```cpp
int push(queue *q,int val)
{
   if(q->count==q->size) return 0;//如果队列已满，证明入队不成功 
    insertvector(q->data,q->tail,val);
    q->tail++;//插入以后，tail需要向后挪动一步
    if(q->tail=q->size) q->tail=0;//判断队列末尾是否已满，如果满了，将尾指针指向头部（循环队列）
    q->count++;
    return 1;
}
```

#### pop(出队)

```cpp
int pop(queue *q)
{
    if(empty(q)) return 0; 
    q->head++;//头指针向后移动一步
    q->count--;
    return 1;
}
```

#### clear(销毁队列

```cpp
void clearqueue(queue *q)
{
    if(q==NULL) return;
    clearvector(q->data);//不能直接用free去回收数据区，因为顺序表里面还有data
    free(q);//回收q队列本身
}
```

### 2. 链表封装

### 链表部分

#### typederf(结构体

##### 先定义一个链表的节点

```cpp
typedef struct node
{
    int data;
    node *next;
}node;
```

##### 链表结构

```cpp
typedef struct linklist
{
    node head, tail;//head表示虚拟头节点
}linklist;
```

#### getnewnode(封装元素变为节点)

```cpp
node*getnewnode(int val)
{
    node*p=(node*)malloc(sizeof(node));
    p->data=val;
    p->next=NULL;
    return p;
    
}
```

#### emptylist(查看节点是否为空)

```cpp
int emptylist(linklist *l)
{
    return l->head.next==NULL:
}
```



#### initlinklist(初始化

```cpp
linklist* initlinklist()
{
    linklist *l=(linklist*)malloc(size3of(linklist));
    l->head.next=NULL;
    l->tail=&(l->head);
    return 1;
}
```

#### frontlist(查看元素)

```cpp
int frontlist(linklist *l)
{
    if(emptylist(l)) return 0;
    return l->head.next->data;
}
```

#### inserttail(在尾部插入一个节点

```cpp
int inserttailo(linklist *l,int val)
{
    node *node=getnewnode(val);//先将val封装成一个节点
    l->tail->next=node;//往tail后面再插入一个新的节点
    l->tail=node;//让tail指向node
    return 1;
}
```

#### erasehead(消除链表的第一个节点

```cpp
int erasehead(linklist *l)//跳过那个节点即为删除
{
    if(emptylist(l)) return 0;
    node *p=l->head.next;
    l->head.next=l->head.next->next;//让指向跳过下一位，指向它下一位的下一节点
    if(p==l->tail) l->tail=&(l->head);
    free(p);
    return 1;
}
```



#### clear(销毁)

```cpp
void clearlinklist(linklist *l)
{
    node *p=l->head.next,*q;
    while(p)//用p循环，对链表后面的数据进行遍历，将链表后面的数据清空。
    {
        q=p->next;
        free(p);
        p=q;
    }
    free(l);//释放掉链表本身
}
```



### 队列部分：

#### typederf(结构体

```cpp
typedef struct queue
{
    linklist*l;
    int size,count;//链表不在乎存储空间的大小，也就不需要循环队列，头尾指针也不再需要，链表本身有头节点和尾节点
}queue;
```

#### initqueue(初始化

```cpp
queue *initqueue()//链表不需要初始化的大小为n
{
    queue *q=(queue*)malloc(sizeof(queue));
    q->l=initlinklist();
    q->count=0;
    return q;
}
```

#### empty(判空)

```cpp
int empty(queue*q)
{  
    return q->count==0;
}
```

#### front(查看队首元素)

```cpp
int front(queue *q)
{
    if(empty(q)) return 0;
    return frontlist(q->l);
}
```

#### push(插入)

```cpp
int push(queue *q,int val)
{
    inserttail(q->l,val);
    q->count++;
    return 1;
}
```

#### pop(出队)

```cpp
int pop(queue *q)
{
    erasehead(q->l);
    q->count--;
    return 1;
}
```

#### clear(销毁队列

```cpp
void clearqueue(queue *q)
{
    if(q==NULL) return;
    clearlinklist(q->l);//不能直接用free去回收数据区，因为链表里面还有data
    free(q);//回收q队列本身
}
```
