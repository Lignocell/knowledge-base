# 堆与优先队列

---

## 一、堆

### 堆的定义与分类

- 堆从结构上讲，其实就是一棵<u>完全二叉树</u>，而完全二叉树的定义，可以参考二叉树的那一节；而从本质上讲，其实就是以完全二叉树排序而成的数组。

- 堆可以分为大顶堆与小顶堆，顾名思义，大顶堆便是==最大的==为根节点的完全二叉树，从上往下依次递减；而小顶堆则是==最小的==为根节点的完全二叉树。

### 堆的操作

+ 插入：无论是大顶堆，还是小顶堆，再进行插入操作时，都是向尾部进行插入，然后与它的父节点进行比较，如果比父节点要大（小），那么就让二者进行交换，进而进行递归，直到符合堆的结构规则为止。

- 弹出：与插入相反，当进行弹出操作时，让需要弹出的节点与根节点进行交换，并从头部弹出该节点以实现删除操作，然后让最后一个节点移入头部元素，然后与子节点进行比较，递归，完成删除操作。

## 二、优先队列

优先队列包含大顶堆，小顶堆与其他实现，由于同样是尾插头删，与队列的性质相似，但又不完全相同。
不同点：优先队列头删的元素是最大值（最小值），而不是先进先出。

## 三、代码实现

### 结构体定义

```c
typedef struct PriorityQueue
{
    int *data,*__data;
    int n,size;//size是最大容量，n是当前元素的数量
}PQ;
```

### 结构体初始化

由于当下标从0开始时，完全二叉树推断子节点的计算过程会比下标从1开始时的过程多一点，因此我们需要进行下标偏移操作。

==下标偏移==：
当`__data`的初始位置为0时，让`data`指向`__data`的前一号位置，因此data第1号位置指向的是`__data`第0号位置。

```c
PQ *initPQ(int size)
{
    PQ* p=(PQ*)malloc(sizeof(PQ));//给优先队列开辟内存
    p->__data=(int)malloc(sizeof(int)*size);//给data开辟内存
    p->data=p->__data-1;
    p->size=size;
    p->n=0;
    return p;
}
```

### 清空

```c
void freePQ(PQ *p)
{
    if (p == NULL) return;
    free(p->data);
    free(p);
    return;
}
```

### 杂项

```c
//判断是否为空
int emptyPQ(PQ* p)
{
    return p->n == 0;
}
//判断是否为空
int fullPQ(PQ* p)
{
    return p->n == p->size;
}
//判断是否为根节点
int top(PQ* p)
{
    return p->data[1];
}
```

### 插入操作

```c
int push(PQ*p,int x)
{
    if(full(p)) return;
    p->n++;
    p->data[p->n]=x;//n号位置就是此时开辟的空位
    up_data(p->data,p->n);
    return 1;
}
```

### 删除操作

```c
int pop(PQ*p)
{
    if(empty(p)) return;
    p->data[1]=p->data[p->n];//此时n指向的是要删除的节点的位置
    p->n--;
    down_data(p->data,1);
    return 1;
}
```

### 向上比较

```c
void up_data(int *data,int i)
{
    if(i==1) return;
    if(data[i]>data[i/2])//当i为最尾端元素时，此时父节点是i/2
    {
        swap(data[i],data[i/2])
    }
    up_data(data,data[i/2]);//然后继续向上调整
    return;
}
```

### 向下比较

```c
void down_data(int* data, int i)
{
    int largest = i;
    int left = 2 * i; // 左子节点
    int right = 2 * i + 1; // 右子节点

    // 如果左子节点存在且比当前节点大
    if (left <= n && data[left] > data[largest])
        largest = left;

    // 如果右子节点存在且比当前节点大
    if (right <= n && data[right] > data[largest])
        largest = right;

    // 如果largest不是当前节点，交换并递归下调
    if (largest != i)
    {
        swap(data[i], data[largest]);
        down_data(data, largest);
    }
    return;
}
```
