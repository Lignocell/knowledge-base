# 二叉树

---

## 一、定义

在一个树形结构中，每个节点*最多*只有两个子节点的树形结构叫做二叉树。

## 二、结构讲解

- 每个节点的度最多为2。（以下所有的度默认均为出度）

- 度为0的节点比度为2的节点=多一个=。

- 一个节点的两个子节点，一个被称为左孩子，一个被称为右孩子。

## 三、特殊种类

1. #### 完全二叉树

```
        1
       / \
      2   3
     / \ / 
    4  5 6  
```

##### 特点:

- 除最后一层以外，上面层的节点均有两个子节点。
- 最后一层缺少一个最右边的节点。
- 编号为n的子节点，可以通过父节点的编号计算子节点的编号，即节省了空间，增加了时间
   1. 左孩子的编号为n。
   1. 右孩子的编号为n+1。
- 可以用==连续空间==来存储。

2. #### 满二叉树

```
        1
       / \
      2   3
     / \ / \
    4  5 6  7
        / \
       8   9
```

##### 特点

**没有**度为1的节点。

3. #### 完美二叉树

```
        1
       / \
      2   3
     / \ / \
    4  5 6  7
```

##### 特点

每一个节点都是满的子节点。

## 四、转换，将其他树形结构转化为二叉树

#### 方法：左孩子右兄弟法

以下是一个三叉树的图示

```
          1
        / | \
       2  3  4
      /|  |   
     5 6  7    
```

通过该方法将三叉树转化为二叉树，左边写子节点，右边写兄弟)

```
        1
       / 
      2   
    /   \
   5     3
   \    / \
    6   7  4
```

==通过该方法用来节省空间=

- 在第一个三叉树中，需要的空间为3*7=21个空间。
- 在第二个二叉树中，需要的空间为2*7=14个空间。
- k叉树节省的空间为`k*n-2*n=n*(k-2)`个空间。

## 五、代码演示

```cpp
#include <iostream>
#include <queue> // 使用队列
#include <stack> // 使用栈
#include <time.h>
#define max 10

using namespace std;

typedef struct node 
{
    int key;
    struct node* left, * right;//定义左孩子和右孩子
} node;

//将key值包装成节点
node* getnewnode(int key) 
{
    node* p = (node*)malloc(sizeof(node));//开辟节点空间
    p->key = key;//将key值赋值给节点
    p->left = p->right = NULL;
    return p;
}
//插入节点
node* insert(node* root, int key) 
{
    if (root == NULL) return getnewnode(key);
    if (rand() % 2) root->left = insert(root->left, key);//将左节点与右节点区分开来
    else root->right = insert(root->right, key);
    return root;
}
//销毁节点
void clear(node* root) {
    if (root == NULL) return;
    clear(root->left);
    clear(root->right);
    free(root);
}
//广度优先遍历
void bfs(node* root) 
{
    if (root == NULL) return;
    queue<node*> q; // 创建队列
    q.push(root); // 将根节点加入队列

    while (!q.empty()) 
    {
        node* current = q.front(); // 获取队首元素
        q.pop(); // 移除队首元素

        // 处理当前节点
        if (current->left) 
        {
            q.push(current->left);
            cout << current->key << "->" << current->left->key << endl;//根节点->左孩子
        }
        if (current->right)
        {
            q.push(current->right);
            cout << current->key << "->" << current->right->key << endl;//根节点->右孩子
        }
    }
}

int toto;
void dfs(node* root) {
    if (root == NULL) return;

    stack<node*> s; // 创建栈
    s.push(root); // 将根节点加入栈中

    while (!s.empty()) {
        node* current = s.top(); // 获取栈顶元素
        s.pop(); // 移除栈顶元素

        // 处理当前节点
        toto++;
        int start = toto;

        cout << current->key << ":[" << start << ","; // 输出当前节点的开始序号

        // 先将右子树压入栈，然后压入左子树
        if (current->right) s.push(current->right);
        if (current->left) s.push(current->left);

        toto++;
        int end = toto; // 记录结束序号
        cout << end << "]" << endl; // 输出当前节点的结束序号
    }
}

int main() {
    srand(time(0));
    toto = 0; // 初始值toto
    node* root = NULL;
    for (int i = 0; i < max; i++) {
        root = insert(root, rand() % 100);
    }

    cout << "BFS :" << endl;
    bfs(root); // 层次遍历

    cout << "DFS :" << endl;
    dfs(root); // 深度遍历

    clear(root); // 释放内存
    return 0;
}
```
