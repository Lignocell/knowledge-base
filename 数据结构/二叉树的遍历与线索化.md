# 三种遍历方式与线索化

---

## 一、三种遍历方式

前序遍历：根 左 右
中序遍历：左 根 右
后序遍历：左 右 根

##### 目的：

让结构再转移到另一个计算机时，能够根据遍历方式来复原数据，而不是需要去传输整个**指针信息**（传输到另一个计算机后存储的位置也发生了改变）

### 前序遍历

```
        1
       / \
      2   3
     / \   \
    4  5    6
```

根据根，左，右的方式进行遍历。

1. 先找到根节点。
     `|1|`
2. 左代表左子树，将左子树按<u>前序遍历</u>的方式进行遍历。
    `|1|2|4|5|`
3. 右代表右子树，将右子树按<u>前序遍历</u>的方式进行遍历。
`|1|2|4|5|3|6|`

### 中序遍历

```
        1
       / \
      2   3
     / \   \
    4  5    6
```

根据左，根，右的方式进行遍历。

1. 先找到根节点。
   `|1|`
2. 左代表左子树，将左子树按<u>中序遍历</u>的方式进行遍历。
   `|4|2|5|1|`
3. 右代表右子树，将右子树按<u>中序遍历</u>的方式进行遍历。
   `|4|2|5|1|3|6|`

### 后序遍历

```
        1
       / \
      2   3
     / \   \
    4  5    6
```

根据左，右，根的方式进行遍历。

1. 先找到根节点。
   `|1|`
2. 右代表右子树，将右子树按<u>后序遍历</u>的方式进行遍历。
   `|6|3|1|`
3. 左代表左子树，将左子树按<u>后序遍历</u>的方式进行遍历。
   `|4|5|2|6|3|1|`

想要恢复二叉树的结构，需要依靠前+中，或者后+中；而后不行，因为无法区分跟根节点的位置。

## 二、线索化

左边->前驱
右边->后继

前序遍历， 2 4 5 3 6
中序遍历， 2 5 1 3 6
后序遍历， 5 2 6 3 1

```
        1
       / \
      2   3
     / \   \
    4  5    6
```

线索化主要在做废物利用：由于二叉树每个节点都有两个子节点，在上面的二叉树中，
根据中序遍历，号节点的左边是空，那么四号节点的左子节点指向NULL，右子节点指向了2，同理，根据中序节点的遍历顺序，来确定空子节点指向的位置。

==好处==：让二叉树形成循环的链表，使得不需要借助递归程序就可以进行遍历，并且停在任何一个节点处。

## 三、代码演示

三种遍历方式的代码

```cpp
#include<iostream>
#include<time.h>
#define max 10
using namespace std;

typedef struct node
{
    int key;
    node* left, *right;
}node;

//初始化节点
node *getnewnode(int key)
{
    node* p = new node;
    p->key = key;
    p->left =p-> right = NULL;
    return p;
}

//插入随机节点
node* insert(node* root, int key)
{
    if (root == NULL) return getnewnode(key);
    if (rand() % 2) root->left = insert(root->left, key);
    else root->right = insert(root->right, key);
    return root;
}

//前序遍历（注意三种遍历方式输出的位置不同）
void pre_order(node* root)
{
    if (root == NULL) return;
    cout << root->key << " ";
    pre_order(root->left);
    pre_order(root->right);
}

//中序遍历
void in_order(node* root)
{
    if (root == NULL) return;

    in_order(root->left);
    cout << root->key << " ";
    in_order(root->right);
}

//后续遍历
void post_order(node* root)
{
    if (root == NULL) return;

    post_order(root->left);
    post_order(root->right);
    cout << root->key << " ";
}

//清除
void clear(node* root)
{
    if (root == NULL) return;
    clear(root->left);
    clear(root->right);
    delete root;
}

int main()
{
    srand(time(0));
    node* root = NULL;
    for (int i = 0; i < max; i++)
    {
        root = insert(root, rand()%100);
    }

    pre_order(root);
    cout << endl;
    in_order(root);
    cout << endl;
    post_order(root);
    cout << endl;

    clear(root);

    return 0;
}
```
