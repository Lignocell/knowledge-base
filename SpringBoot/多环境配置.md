# 多环境配置

在日常的开发中，我们的项目会有多个环境，例如开发环境（develop），也就是我们研发过程不断敲代码的过程，生产环境（production）项目开发完成，可以在服务器上运行了；不同环境下，可能我们的配置文件也存在不同，但是我们不可能在切换环境的时候重新进行配置文件，所以我们可以将多个环境的配置文件提前写好，进行自由切换。

由于SpringBoot只读取application.properties或是application.yml文件，那么怎么才能实现自由切换呢？SpringBoot为我们提供了一种方式，我们可以通过配置文件进行指定：

```yaml
spring:
profile:
 actiev: dev
```

接着，我们分别创建两个环境的配置文件，application-dev.yml和application-prod.yml分别表示开发环境和生产环境的配置文件，比如开发环境我们使用的服务器端口为8080，而生产环境可以设置为80或443端口，这就需要不同环境的配置文件进行区分：

```yaml
server:
port: 8080
```

```yaml
server:
port: 80
```

这样我们就可以灵活切换了。

SpringBoot自带的LogBack日志系统也是支持多环境配置的，比如我们想在开发环境下输出日志到控制台，而生产环境需要将日志输出到文件中，这时就需要进行环境配置：

```xml
<springProfile name="dev">
    <root level="INFO">
        <appender-ref ref="CONSOLE"/>    
    </root>
</springProfile>

<springProfile name="prod">
    <root level="INFO">
        <appender-ref ref="FILE"/>
    </root>
</springProfile>
```

注意：这里的springProfile是区分大小写的。

那如果我们希望生产环境中不打包开发环境下的配置文件呢？我们目前虽然可以切换开发环境，但是打包的时候依然是所有配置文件都进行打包，但是如果要求开发环境和生产环境分开打包呢？这时，我们需要依靠Maven来解决，Maven可以设置多环境：

```xml
<!--分别设置开发，生产环境-->
<profiles>
    <!-- 开发环境-->
    <profile>
        <id>dev</id>
        <activation>
            <activeByDefault>true</activeByDefault>
        </activation>
        <properties>
            <environment>dev</environment>
        </properties>
    </profile>
    <!-- 生产环境 -->
    <profile>
        <id>prod</id>
        <activation>
            <activeByDefault>false</activeByDefault>
        </activation>
        <properties>
            <environment>prod</environment>
        </properties>
    </profile>
</profiles>
```

接着，我们需要根据环境的不同，排除其他环境的配置文件：（除了dev和prod，业务中可能还存在其他的配置，我们需要先一步到位全部排除，然后再将需要的添加）

```xml
<resources>
<!--排除配置文件-->
    <resource>
        <directory>src/main/resources</directory>
        <!--先排除所有的配置文件-->
        <excludes>
            <!--使用通配符，当然可以定义多个exclude标签进行排除-->
            <exclude>application*.yml</exclude>
        </excludes>
    </resource>

    <!--根据激活条件引入打包所需的配置和文件-->
    <resource>
        <directory>src/main/resources</directory>
        <!--引入所需环境的配置文件->
        <filtering>true</filtering>
        <includes>
            <include>application.yml</include>
            <!--根据maven选择环境导入配置文件-->
            <include>application-${environment}.yml</include>
        </includes>
    </resource>
</resources>
```

接着，我们可以直接将Maven中的environment属性传递给SpringBoot的配置文件，在构建时替换对应的值：

```yaml
spring:
profiles:
active: '@environment@'  #注意yaml文件配置需要单引号，否则报错
```

这样，根据我们Maven环境的切换，SpringBoot的配置文件也进行同样的切换。

最后我们打开Maven栏目，就可以进行切换了，直接勾选即可，注意切换环境时需要重新加载Maven项目，否则不会生效。
