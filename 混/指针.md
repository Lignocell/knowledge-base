# c语言难点之指针

---

## 一、定义

### 1、区分

```c
int p;//p是整型变量
int *p;//p先于*结合，说明p是一个指针；在与int结合，说明p这一指针指向的地址的值是一个整型变量。
int p[3];//p先于【】结合，说明p是一个数组；在与int结合，说明该数组内的元素都是整型。
int *p[3];//p先于【】结合，因为【】的优先级比*高，说明p是一个数组；在与*结合，说明数组里的元素都是指针；在与int结合，说明数             组里的指针所指向的地址的值都是整型。
int (*p)[3];//p先与*结合，说明p是一个指针；在与【】结合，说明，该指针指向的所指向的地址的值是数组的地址；再与int结合，说明              数组里的元素都是整型。

int **p;//p先与*结合，说明p是一个指针；再与第二个结合，说明p这个指针指向的地址存放的是另一个指针（即指针中存放了另一个指             针）；再与int结合，说明p这个指针中存放的指针所指向的地址的值是一个整型。
int p(int);//p先与（）结合，说明p是一个函数，该函数有一个int类型的参数；在与int结合，说明该函数返回值是一个int的类型。
int (*p)(int);//p先与*结合，说明p是一个指针；再与（）结合，说明指针指向的地址中存放的是一个函数；再与（int）结合，说明，该                 函数有一个int类型的参数；最后在与外面的int结合，说明该函数的返回值是int类型。
int *(*p(int))[3];//p先与（）结合，说明p是一个有着int类型的参数的函数；再与*结合，说明函数返回的是一个指针；然后再和【】                    结合，说明该指针指向的地址中存放的是一个数组；再与*结合，说明该数组中存放的全部都是指针；最后再与int                     结合，说明指针指向的地址的值是int型。
```

==研究指针时，必须要清楚四个内容：==

- 指针的类型。
- 指针所指向的类型。
- 指针的值或者叫指针所指向的内存区。
- 指针本身所占据的内存区。

比如：

```c
int *p;
char *p;
int **p;
int(*p)[3];
int*(*p)[3];
```

#### 1、指针的类型

##### 语法：

把代码中的指针的名字去掉，就是指针本身的类型。

```c
int *p;//指针的类型为int*
char *p;//指针的类型为char*
int **p//指针的类型为int**
int(*p)[3];//指针的类型为int(*)[3]
int*(*p)[3];//指针的类型为int*(*)[3]
```

#### 2、指针所指向的类型

##### 语法：

- 当通过指针来访问指针所指向的内存区时，指针所指向的类型决定了编译器把那片内存区里的内容当作什么来看待。

- 把指针的名字与名字左边的指针声明符去掉，就是指针所指向的类型。

```c
int *p;//指针所指向的类型为int
char *p;//指针所指向的类型为char
int **p;//指针所指向的类型为int*
int(*p)[3];//指针所指向的类型为int()[3]
int*(*p)[3];//指针所指向的类型为int*()[3]
```

#### 3、指针的值——指针所指向的内存区

##### 语法：

- 指针的值是指针本身存储的数值，这个值被当作一个地址。

- 32位程序中，所有类型的指针的值都是32位整数，因为32位程序里内存地址全都是32位长。

- 指针所指向的内存区是：**从指针所指向的地址（也就是内存区的首地址）开始，到sizeof(指针所指向的类型**。整一片区域都是指针所指向的内存区。

- 当指针的值是XX，则说明该指针的指向了以XX为首地址的内存区；当指针指向了一片内存区，则说明该指针的值是这块内存区域的首地址。

- 区分指针指向的类型与指针所指向的值。在代码中，指针所指向的类型已经有了，**但由于指针还未初始化，所以它所指向的内存区还不存在。*

#### 4、指针本身所占据的内存区

##### 语法：

- `sizeof(指针的类型`测算。

- 32位程序里，指针本身占据了4个字节的长度。

### 2、区分`int*p=&a`

```c
int*p=&a//正确,依据上面的内容，p的数据类型是int*，而 a 的数据类型也是int*
*p=&a//错误，左值的数据类型为int，a的数据类型为int*
*p=a;//正确
p=&a;//正确
```

区别：

- *p代表的是一个值；p是一个地址。

- *代表p指向的地址的值，意味着取值。

- &是取地址的符号，取得是地址。

- *p就是取p指针所指向的地址的值，&a就是取a的地址。

### 3、区分a 和 a

|                int *p=a;                |                          int*p=&a;                           |
| :-------------------------------------: | :----------------------------------------------------------: |
| 这里的p指针指向了a[0]这一单个的数组元素| 这里的a相当于a整个数组，p只是一个`int*`类型的指针只能匹配单个数组 |

  

## 二、指针的算术运算

### 例一：

```c
char a[20];
int*p=(int*)a;//强制类型转换并不会改变a的类型，相当于新开辟了一个指针，不会影响原来的。意味着读取时，编译器会以int的方式读                 取a这个数组。
p++;
```

+ 依照上面的内容，p的类型为int*，p所指向的类型为int，它被初始化为指向整型变量a。
+ p++：p的值加上了sizeof(int)，在32位程序中，加上了4个字节（int占据的字节），所以p指向的地址由原来的变量a的地址向高地址的方向移动了4个字节。

### 例二：

```c
int array[20]={0}; 
int *ptr=array; 
for(i=0;i<20;i++) 
 { 
(*ptr)++; //指的是将ptr进行解引用，即array[0]，这时进行加一，结果为array[0]=1
   ptr++，//指的是将ptr下标加，即array[0]->array[1]
 } 
```

### 例三：

```c
char a[20]="you_are_a_gril";
int *p=(int*)a;
p+=5;
```

- p+=5:p的值加上了sizeof(int)*5，即向高地址的方向移动了20个字节，虽然移动到a的合法范围以外，但在语法上没有问题。

### 例四：

```c
char a[20]=" You_are_a_girl"; 
char *p=a; 
char **ptr=&p; //即ptr这一指针内存放的地址为p的地址
printf("**ptr=%c\n",**ptr); //进行两次解引用，第一次得到了p的地址，第二次得到了p这个地址所代表的值，即a[0]
ptr++; //ptr是一个指向char*类型的区域，该区域未定义，所以ptr++移动到了一个非法区域
printf("**ptr=%c\n",**ptr); //再次输出时，**ptr无法解析，将会输出一个随机值
```

### 三、运算符&*

- &为取地址运算符
  - &a的运算结果是一个指针，指针的类型为a的类型加*，指针所指向的类型就是a的类型，指针所指向的地址就是a的地址。

- *间接运算符
  - *p的结果是p所指向的东西，他的类型为p指向的类型，他所占用的地址为p指向的地址。

### 四、指针表达式

- 一个表达式的结果如果是一个指针，那么这个表达式就叫指针表达式

- 指针表达式同样拥有四个要素，即：指针本身的类型，指针所指向的类型，指针的值或指针所指向的内存区，指针本身所占据的内存区。

## 五、强制类型转换

#### 代码：

```c
float f=12.3;
float *fps=&f;
int *p;
```

#### 解释：

- 要想将p赋值给f，需要用到强制类型转换，==p=(int*)&f==。

- 强制类型转换的结果是一个新指针，该指针的类型为(int*),他指向的类型为int，他指向的地址为原指针指向的地址，而原来指针p的一切属性都没有被更改。
- 一个函数如果使用了指针作为形参，必须保证形参和实参类型一致，否则就需要强制转换。
