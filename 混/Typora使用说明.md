# Typora使用说明



## 一、标题
### 语法：
#(一级标题)，##(二级标题)，###(三级标题)——以此类推（井号和文本之间要有空格）

### 代码：


```c
# 一级标题## 二级标题
###  三级标题
```

### 快捷键：

+ ctrl+数字16可以快速将文本改成1~6级的标题
+ ctrl+0将文本变成普通文本
+ ctrl+加号/减号可以对级别进行加和减

## 三、文字显示
### 1、字体
#### 语法：
+ 粗体：用一对星号包含+ 删除线：用一对双飘号包裹
+ 下划线：用一对u标签包裹
+ 斜体：用一对单星号包裹
+ 高亮：用一对双等号包裹

#### 代码：
```
**这是粗体**
~~这是删除线~~
<u>这是下划线</u>
*这是斜体*
==这是高亮==
```

#### 效果：
+ **这是粗体**
+ ~~这是删除线~~
+ <u>这是下划线</u>
+ *这是斜体*
+ ==这是高亮==

#### 快捷键：

+ 加粗：ctrl+B
+ 删除线：ctrl+alt+5
+ 下划线：ctrl+U
+ 斜体：ctrl+I

==注意：当*冲突时，可以输入”星号反斜线“进行转义（转义字符）==

## 四、列表
### 1、无序列表
#### 代码：
```
同一类：*/-/+ +空格
不同类：
ctrl+shift+[    (降低层次)
ctrl+shift+]    (升高层次)
```

#### 效果：
##### 1、只有同一种类别：

+ 苹果
+ 香蕉
+ 橘子

##### 2、子集类：
+ 一级分类  - 二级分类
    + 三级分类

### 2、有序列表：

##### 代码：
```
数字+.+空格
```

##### 效果：
1. fffhf
2. jfjf
3. ffjfl

### 3、任务列表：

##### 代码：
```
-+空格+[空格]+空格
```

##### 效果：
- [x] 吃早餐
+ [ ] 锻炼
