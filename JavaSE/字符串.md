# 字符串

## String类

String本身是一个类，只不过它有些特殊，每个用双引号引起来的字符串，都是String来的实例化对象。

```java
public static void main(String[] args){
    String str="Hello World";
    }
```

我们也可以象征性地使用一下new关键字：                       

```java
public static void main(String[] args) {
    String str = new String("Hello World!");  //这种方式就是创建一个新的对象
}
```

注意，如果是直接使用双引号创建的字符串，如果内容相同，为了优化效率，那么始终都是同一个对象：                      

```java
public static void main(String[] args) {
    String str1 = "Hello World";
    String str2 = "Hello World";
    System.out.println(str1 == str2);
}
```

但是如果我们使用构造方法主动创建两个新的对象，那么就是不同的对象了：       

```java
public static void main(String[] args) {
    String str1 = new String("Hello World");
    String str2 = new String("Hello World");
    System.out.println(str1 == str2);
}
```

如果我们想判断String类型的两个变量是否相同，不要去使用`=`而是去使用`equals`，Strings重载了equals来帮助我们判断：

```java
public static void main(String[] args) {
    String str1 = new String("Hello World");
    String str2 = new String("Hello World");
    System.out.println(str1.equals(str2));   //字符串的内容比较，一定要用equals
}
```

### 现在我们来学习String类的方法：

#### length求长度

```java
public static void main(String[] args) {
    String str1 = new String("Hello World");
    System.out.println(str1.length());
```

因为双引号里面本身就是一个实例化对象，所以我们可以直接用，虽然看上去有点奇怪

```java
public static void main(String[] args){
    System.out.println("Hello World".length());
}
```

#### substring分割字符串

```java
public static void main(String[] args) {
    String str = "Hello World";
    String sub=str.substring(0,3);//分割字符串的0号位置
    System.out.println(sub);
```

#### split分割

```java
public static void main(String[] args) {
    String str = "Hello World";
    String[] ss=str.split(" ");//以空格为界限，将字符串一分为二
    for(string sw:ss){
     System.out.println(sw);
    }
```

#### 字符串与字符数组转换

##### 字符串转数组toCharArray

```java
public static void main(String[] args) {
    String str = "Hello World";
    String[] arr=str.toCharArray();
    System.out.println(arr);
```

##### 数组转字符串

```java
public static void main(String[] args) {

```

## StringBuilder类

在我们原来的学习中，我们都是在用`+`和`-`在进行字符串的拼接，那么，如果多个字符串进行拼接，其实是在多次创建对象，那么我们可以使用StringBuilder类型创建一个新的变量，来进行多次拼接：

```java
public static void main(String[] args){
    String str1 = "你看";
    String str2 = "杩?;
    String str3 = "汉堡";
    String str4 = "做滴";
    String str5 = "行不行";
    StringBuilder build=new StringBuilder();
    build.append(str1).append(str2).append(str3).append(str4).append(str5);
    System.out.println(build.toString());
}
```

StringBuilder其实就是相当于一个编辑器，来弥补字符串不能修改的不足：

```java
public static void main(String[] args){
    StringBuilder build=new StringBuilder();
    build.append("AAA");
    build.append("BBB");
    System.out.println(build.toString());
}
```

同理也支持裁剪操作：

```java
public static void main(String[] args){
    StringBuilder build=new StringBuilder("AAABBB");
    build.delete(2,4);//删除2~4的字符
    System.out.println(builder.toString());
}
```

## 正则表达式

正则表达式其实是用于对字符串的匹配，当我们想要对一串字符串进行判断是否符合格式时，比如对邮箱进行判断，那么编写java程序有可能会有一些麻烦，那么我们可以使用正则表达式来进行判断。

下面有一个判断的例子：

```java
public static void main(String[] args) {
    String str = "oooo";
    System.out.println(str.matches("o+"));//matches是对正则表达式进行匹配，成功返回true，失败返回false
```

用于满足匹配的规则如下，一般称为限定符：

|  字符  |                 描述                  |
| :----: | :-----------------------------------: |
|   x*   |      匹配字符x出现一次或者多次      |
|   x+   |      匹配字符x出现一次或者多次      |
|  x?  |       匹配字符x出现零次或一次      |
|  x{n}  |        匹配字符x恰好出现了n次        |
| x{n,}  |        匹配字符x至少出现了n次        |
| x{n,m} | 匹配字符x至少出现了n次，最多出现了m次|

同理：

|  字符  |                             描述                             |
| :----: | :----------------------------------------------------------: |
| [abc]  |        匹配字符串里面是否有abc三个字符（有返回true）        |
| [^abc] |       匹配字符串里面是否有abc三个字符（没有返回true）       |
| [A-B]  |                     匹配这个范围内的字符                     |
|   .    |     匹配除了换行符（\n,\r）以外的字符，相当于[ ^\n\r ]。    |
| [\s\S] | 匹配所有。\s是匹配所有的字符，包括换行；\S是匹配所有的字符，不包括换行。|
|   \w   |          匹配字母，数字，下划线。等价于[A-Za-z0-9]           |
