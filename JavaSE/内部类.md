# 内部类

顾名思义，内部类，就是创建在内部的类。那么是在哪个内部创建的类呀，其实他是有分类的。

## 一、成员内部类

我们可以直接在类的内部定义一个类

```java
public class Test{
    public class Inner{//内部类也是类，可以在里面定义变量，方法，甚至可以直接套娃。
        public void say(){
            System.out.println("我是成员内部类");
        }
    }
}
```

成员内部类和成员方法、成员变量一样，是对象所有的，而不是类所有的，如果我们要使用成员内部类，那么我们需要：

```java
public static void main(String[] args){
    Test t=new Test();//先创建一个对象
    Test.Inner i=t.new Inner();//成员内部类的类型名称为外部类.内部类名称
}
```

我们也可以使用成员内部类的方法：

```java
public static void main(String[] args){
    Test t=new Test();
    Test.Inner i=t.new Inner();
    i.say();
}
```

注意：成员内部类同样有访问权限，如果我们把权限改为private，那么外部同样无法访问这个类了。

特别注意一下，成员内部类是可以访问外部变量的，是成员外部的变量：

```java
public class Test{
    private final String name;
    
    public Test(String name){
        this.name=name;
    }
    
    public class Inner{
       public void say(){
           System.out.println("我是成员内部类" + name);
           //成员内部类
       } 
    }
}
```

注意，外部类是无法直接访问内部类的，需要使用内部类提供的公共方法。

如果我们内部类定义了一个同名的变量，那么我们如何明确使用哪一个呢：

```java
public class Test{
    private final String name;
    
    public Test(String name){
        this.name=name;
    }
    
    public class Inner{
        String name;
        public void say(String name){
            System.out.println(name);//就近原则，使用的是say方法的参数name
            System.out.println(this.name);//在内部类使用this，那么指的是内部类的name
            System.out.println(Test.this.name);
            //如果指定外部类对象，那么需要在前面添加外部类名称
        }
    }
}
```

同理：

```java
public class Inner {

    String name;
    public void test(String name){
        this.toString();		//内部类自己的toString方法
        super.toString();    //内部类父类的toString方法
        Test.this.toString();   //外部类的toSrting方法
        Test.super.toString();  //外部类父类的toString方法
    }
}
```

所以一般而言，内部类往往是在内部自己使用的。

## 二、静态内部类

静态内部类就像静态方法和静态对象一样，是属于类的，可以直接创建和使用。

```java
public class Test {
    private final String name;

    public Test(String name){
        this.name = name;
    }

    public static class Inner {
        public void say(){
            System.out.println("我是静态内部类，");
        }
    }
}
```

不需要依附任何对象，我们可以创建静态内部类的对象：

```java
public static void main(String[] args){
    Test.Inner i=new Test.Inner();//这里可以直接new对象
    i.say();
}
```

静态内部类是静态的，所以相对于外部而言，整个内部类的内部是无法访问到外部的非静态内容的（外部的静态内容是可以访问到的）。

影响的是内部对外部的引用，内部类的内部定义的变量是不影响的。

## 三、局部内部类

局部内部类就和局部变量一样，可以在方法中直接定义：

```java
public class Test {
    private final String name;

    public Test(String name){
        this.name = name;
    }
    public void hello(){
        class Inner{  //直接在方法中创建局部内部类
            
        }
    }
    
}
```

既然是在方法中声明的类，那么作用范围只能是在方法中了：

```java
public class Test{
    public void hello(){
        class Inner{
            public void say(){
                System.out.println("我是局部内部类");
            }
        }
        Inner i=new Inner();//局部内部类直接使用类名就行
        i.say();
    }
}
```

局部内部类的使用频率很低，了解就可以，基本上是不会使用的。

## 四、匿名内部类

匿名内部类相当于局部内部类的简化版，使用频率很高。

还记得我们在之前学习的抽象类和接口吗？在抽象类和接口中都会含有某些抽象方法需要子类去实现，我们当时已经很明确地说了不能直接通过new的方式去创建一个抽象类或是接口对象，但是我们可以使用匿名内部类。 

```java
public abstract class Student {
    public abstract void test();
}
```

正常情况下，要创建一个抽象类的实例对象，只能对其进行继承，先实现未实现的方法，然后创建子类对象。

我们可以在方法中使用匿名内部类，将其中的抽象方法实现，并直接创建实例对象：

```java
public static void main(String[] args){
    Student s=new Student(){  //后面加上大括号，把未实现的方法实现
        @Override
        public void test(){
            System.out.println("我是匿名内部类实现");
        }
    };
    s.test();
}
```

此时创建的Student的对象，就是一个已经实现了抽象方法的对象，这个抽象类直接就定义好了，甚至连名字都没有，就可以直接创出对象。

匿名内部类同样可以使用类中的属性：

```java
Student s=new Student(){
    int a=0;
    @Override
    public void test(){
        System.out.println(a+"我是匿名内部类实现");
    }
};
```

同样的，接口也可以通过这种匿名内部类的形式，直接创建一个匿名的接口实现类：            

```java
public static void main(String[] args) {
    Study study = new Study() {
        @Override
        public void study() {
            System.out.println("我是学习方法，");
        }
    };
    study.study();
}
```

当然，并不是说只有抽象类和接口才可以像这样创建匿名内部类，普通的类也可以，只不过意义不大，一般情况下只是为了进行一些额外的初始化工作而已。

## 五、表达式

特别的，如果一个接口有且只有一个待实现的抽象方法，那么我们可以将匿名内部类写成一个Lambda方法。

```java
public static void main(String[] args){
    Study ss=()->System.out.println("我是学习方法。");
    ss.study();
}
```

在初始阶段，其实可以将Lambda表达式看成匿名内部类的简写。

以下是Lambda表达式的代码规范：

- 表达式只允许实现接口类，不允许抽象类。

- 接口内部有且只有一个抽象方法（可以有多个方法，但必须保证其他方法有默认实现，必须留一个抽象方法）。

比如说之前的Study接口，只要求实现一个无参构造方法。

```java
()->System.out.println("我是学习方法。");//跟之前流程控制一样，如果只有一行代码花括号可省略
```

如果有返回值和参数的话：

```java
public static void main(String[] args){
    Study ss=(a)->{
        System.out.println("我是学习方法。");
        return a+"hhh";
    };
    System.out.println(ss.study(10));
}
```

如果方法里只有一个return关键字的话，可以直接省略：

```java
Study ss=(a)->{
    return "今天学会"+a;
};
```

```java
Study ss=a->"今天学会"+a;
```

如果一个方法的参数需要一个接口的实现:

```java
public static void main(String[] args){
    test(a->"今天学会"+a);
}
private static void test(Study s){
    s.study(10);
}
```

当然，对于一个已经实现的方法，如果我们想要直接作为接口抽象方法的实现，我们可以实现方法的引用。

## 六、方法引用

方法引用就是将一个已经实现的方法将其直接作为接口中抽象方法的实现。

```java
public void Study{
    int sum(int a,int b);//待实现的求和方法
}
```

```java
public static void main(String[] args){
    Study ss=(a,b)->a+b;
}
```

只不过，Integer中存在sum这个方法，所以我们还可以简化：

```java
public static void main(String[] args){
    Study ss=(a,b)->Integer.sum(a,b);
    System.out.println(ss.sum(10,10));
}
```

不过我们发现，Integer所定义的值和我们自定义的值一模一样，因此：

```java
public static void main(String[] args){
    Study ss=Integer::sum;  //使用双冒号来进行方法引用
    System.out.println(ss.sum(10,10));
}
```

方法引用本质上就是将已经实现的方法作为接口中抽象方法进行实现，事实上，任何方法都可以进行方法引用。

如果是普通的成员方法我们，同样需要使用对象来进行方法的引用：

```java
public static void main(String[] args){
    Main m=new main();
    Study s=main::lbwnb();  
    //成员方法因为需要具体对象使用，所以说只能使用 对象::方法引用的形式
}
}
publc String lbwnb(){
    retrun "hhh";
}
```

因为现在只需要一个String类型的返回值，由于String的构造方法在创建对象时也会得到一个String类型的结果，所以说：                     

```java
public static void main(String[] args) {
    Study study = String::new;    //没错，构造方法也可以被引用，使用new表示
}
```

反正只要是符合接口中方法的定义的，都可以直接进行方法引用。
