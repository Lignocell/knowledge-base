# 包装类

## 基本类型的包装类

对于java来说，这门语言并不是纯面向对象的语言，但是却是拥有面向对象的语言，现在我们需要将基本数据类型进行包装，使其能通过对象的方式进行使用。

### 包装类介绍

所有包装类的结构如下：

```
                      Object
               /         |        \
          Character    Number     Boolean
                     //  |  \\
             Byte Short Integer Float Double
```

| 基本数据类型 | 引用数据类型 |
| :----------: | :----------: |
|     byte     |     Byte     |
|    short     |    Short     |
|     int      |   Integer    |
|    float     |    Float     |
|    double    |    Double    |
|   boolean    |   Boolean    |
|  character   |  Character   |

这里我们直接用Integer举例：

```java
public static void main(String[] args){
    Integer i=new Integer(10);//将 10 包装成一个Integer类型的变量
}
```

包装类实际上就是将基本类型给封装成了一个类，我们通过反编译可以看到long中封装的函数：

```java
private final int value;  //类中实际上就靠这个变量在存储包装的值

public Integer(int value) {
    this.value = value;
}
```

包装类型支持自动封装，因此我们可以按照int类型的定义直接定义Integer：

```java
public static void main(String[] args){
    Integer i=10;
}
```

这是怎么做到的呢，为什么，10作为int类型的变量为什么可以直接赋值给了Integer呢，其实这里就是自动装箱：

```java
public static void main(String[] args){
    Integer i=Integer .valueOf(10);//上面的写法和这里是等价的
}
```

得益于自动装箱与自动拆箱的机制，我们可以很轻松的让Integer很轻松的参与到基本数据类型的计算当中：

```java
public static void main(String[] args){
    Integer a=10,b=10;
    int c=a*b;  //直接自动拆箱参与到基本类型参与到计算当中
    System.out.println(c);
}
```

因为包装类是一个类，不是基本数据类型，所以说两个对象是不相等的：

```java
public static void main(String[] args){
    Integer i=new Integer(10);
    Integer j=new Integer(10);
    
    System.out.println(i==j);//这里的结果是是不想等
}
```

但是对于自动装箱来说，会把两个相同的值指向同一个对象，以便提高效率，所以结果是相等的：

```java
public static void main(String[] args){
    Integer i=10;
    Integer j=10;
    
    System.out.println(i==j);//这里结果是相等的
}
```

以下是通过反编译得到的结果：

```java
public static Integer valueOf(int i) {
    if (i >= IntegerCache.low && i <= IntegerCache.high)   //这里会有一个IntegerCache，如果在范围内，那么会直接返回已经提前创建好的对象
        return IntegerCache.cache[i + (-IntegerCache.low)];
    return new Integer(i);
}
```

IntegerCache会默认缓存 -128~127内所有的值，这些值会默认包装成类放进数组中存放，因为这些值的使用频率非常高，会直接自动装箱为Integer类型的对象，如果全都创建对象，会造成占用内存过多。

如果超出这个范围那么结果就不同了。

包装类同样提供了不同的方法：

1. 包装类支持字符串直接转换：

	```java
	public static void main(String[] args){
	    Integer i=new Integer("666");//直接将字符串转换为数字
	    System.out.println(i);
	}
	```

2. 当然字符串也可以转Integer：

	```java
	public static void main(String[] args){
	    Integer i=Integer.valueOf("666");
	    System.out.println(i);
	}
	```

3. 我们也可以将16进制和二进制的数字进行解码：

	```java
	pubic static void main(String[] args){
	    Integer i=Integer.decode("0xA6");
	    System.out.println(i);
	}
	```

4. 也可以将十进制转换为其他进制的数字：

	```java
	public static void main(String[] args){
	    System.out.println("166");
	}
	```

提供的函数有很多，以下不一一列举了。

### 特殊包装类

BigInteger是用来计算很大数字的包装类，我们知道，long只占据了64bit，那么使用BigInteger就没有限制，可以表示一个很大的数字：

```java
public static void main(String[] args){
    BigInteger i=BigInteger.valueOf(long.MAX_VALUE);//long的最大值
    System.out.println(i);//很容易
}
```

同理，浮点数的精度有限，那么我们可以在使用BigDecimal来实现浮点数的更精确的值来进行运算：

```java
public static void main(String[] args) {
    BigDecimal i=BigDecimal.valueOf(10);
    i=i.divide(BigDecimal.valueOf(3),100,RoundingMode.CEILING);
    //这里是计算10/3的结果，其中将保留小数点后100位，CEILING意味着向上取整,FLOOR是向下取整
```
