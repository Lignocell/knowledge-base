# 基础语法

---

## 关键字

- 会被特殊颜色标记的字体，包括class，public等等。

- 关键字的字母**全部小写**。

## 字面量

##### 类型:

整数类型，小数类型，字符串类型，字符类型，布尔类型，空类型。

##### 注意：

- 字符串是被双引号引起来的内容，无论双引号里面是否为空。

- 字符是被单引号引起来的内容，内容只能是*一个*。

## 制表符

\t，打印时把字符串的长度补齐为8，或8的整数倍。（让视觉效果看起来像是制作表格一般）

## 数据类型

### 整数：

byte，取值范围在-128~127之间。

short，int，long。

long定义时最后面要加L

### 浮点数

float,double。

float定义时最后面要加F

### 字符：

char

### 布尔:

boolean

## 标识符命名规范

### 小驼峰命名法：方法，变量

标识符是一个单词时，全部小写。

当由多个单词组成时，第一个单词的首字母小写，其他单词的首字母大写。

name，firstName

### 大驼峰命名法：类名

标识符是一个单词时，首字母大写。

当由多个单词组成时，每个单词的首字母都要大写。

Student，GoodStudent

### 硬性要求

- 不能由数字开头。
- 不能是关键字。
- 区分大小写。
- 可以是下划线和美元符开头。

## 键盘录入

1. 导包：Scanner这个类在哪。类似于头文件包含)

   ```java
   import java.util.Scanner;
   ```

   

2. 创建对象：表示我要开始使用这个类了。

   ```java
   Scanner sc=new Scanner(System.in);
   ```

   

3. 接收数据。

   ```java
   int i=sc.nextInt();
   ```
