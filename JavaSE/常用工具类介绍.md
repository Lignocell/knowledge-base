# 常用工具类

一般而言，工具类都会内置静态方法，因此直接对类名来进行使用。

## 数学工具类

### Math

##### 正常运算

Math是在java.long下包装的类，可以直接使用。

```java
public static void main(String[] args){
    Math.pow(5,3);  //幂次方
    Math.abs(-1);  //求 -1 的绝对值
    Math.max(10,20);  //求最大值
    Math.min(3,4); //求最小值
    Math.sqrt(9);  //求平方根
}
```

#### 三角函数

```java
public static void main(String[] args){
    Math.PI; //表示Π
    Math.sin(Math.PI/2); //正弦
    Math.cos(1);  //余弦
    Math.tan(1);  //正切
    //反三角函数
    Math.asin(1);
    Math.acos(1);
    Math.atan(1);
}
```

可能在某些情况下，计算出来的浮点数会得到一个很奇怪的结果：

```java
public static void main(String[] args) {
    System.out.println(Math.sin(Math.PI));   //计算 sinπ 的结果
}
```

##### 对数函数

```java
public static void main(String[] args) {
    Math.log(Math.E); //其实是ln
    Math.log10(100); //以 10 为底的对数函数
    //可以利用换底公式求出所有想要的对数函数
    double a=Math.log(4)/Math.log(2);//这是求以2为底4的对数，log(2)4=ln4/ln2
}
```

##### 取整

```java
public static void main(String[] args) {
    Math.ceil(4.5);  //向上取整，即5
    Math.floor(4.5); //向下取整，即4
}
```

##### 随机数生成

```java
public static void main(String[] args) {
    Random rr=new Random();
    for(int i=0;i<30;i++){
        System.out.println(rr.nextInt(100)+" ");//nextInt可以创建0~X内的随机数
    }
}
```

## 数组工具类

数组工具类`Arrays`也是属于java.util包的下类，便于操作数组。

##### 打印数组

```java
public static void main(String[] args) {
   int[] arr = new int[]{1, 4, 5, 8, 2, 0, 9, 7, 3, 6};
   System.out.println(Arrays.toString(arr));
}
```

##### 排序数组

```java
public static void main(String[] args) {
    int[] arr = new int[]{1, 4, 5, 8, 2, 0, 9, 7, 3, 6};
    Arrays.sort(arr);    //从小到大排放
    System.out.println(Arrays.toString(arr));
}
```

##### 快速填充

```java
public static void main(String[] args) {
    int[] arr = new int[10];
    Arrays.fill(arr, 66);
    System.out.println(Arrays.toString(arr));
}
```

##### 拷贝数组

```java
public static void main(String[] args) {
    int[] arr = new int[]{1, 2, 3, 4, 5};
    int[] target = Arrays.copyOf(arr, 5);
    System.out.println(Arrays.toString(target));   //拷贝数组的全部内容，并生成一个新的数组对象
    System.out.println(arr == target);
}
```

```java
public static void main(String[] args) {
    int[] arr = new int[]{1, 2, 3, 4, 5};
    int[] target = Arrays.copyOfRange(arr, 3, 5);   //也可以只拷贝某个范围内的内容
    System.out.println(Arrays.toString(target));
    System.out.println(arr == target);
}
```

我们也可以将一个数字的内容拷贝到另一个数组中：

```java
public static void main(String[] args) {
    int[] arr = new int[]{1, 2, 3, 4, 5};
    int[] target = new int[10];
    System.arraycopy(arr, 0, target, 0, 5);   //使用System.arraycopy进行搬运
    System.out.println(Arrays.toString(target));
}
```

对于一个有序数组，我们也可以通过二分搜索快速找到某个元素所对应的位置：

```java
public static void main(String[] args) {
    int[] arr = new int[]{1, 2, 3, 4, 5};
    System.out.println(Arrays.binarySearch(arr, 5));   //二分搜索仅适用于有序数组
}
```

##### 二维数组

那么对于二维数组来说，使用toString时可能会出现一些问题：

```java
public static void main(String[] args) {
    int[][] array = new int[][]{{2, 8, 4, 1}, {9, 2, 0, 3}};
    System.out.println(Arrays.toString(array));
}
```

![image-20220924114142785](https://oss.itbaima.cn/internal/markdown/2022/09/24/L2at7HJi3BKf6jF.png)

那么，我们可以换一种方法：

```java
public static void main(String[] args) {
    int[][] array = new int[][]{{2, 8, 4, 1}, {9, 2, 0, 3}};
    System.out.println(Arrays.deepToString(array));    //deepToString方法可以对多维数组进行打印
}
```

同样的，因为数组本身没有重写equals方法，所以说无法判断两个不同的数组对象中的每一个元素是否相同，Arrays也为一维数组和多维数组提供了相等判断的方法：                     

```java
public static void main(String[] args) {
    int[][] a = new int[][]{{2, 8, 4, 1}, {9, 2, 0, 3}};
    int[][] b = new int[][]{{2, 8, 4, 1}, {9, 2, 0, 3}};
    System.out.println(Arrays.equals(a, b));   //equals仅适用于一维数组
    System.out.println(Arrays.deepEquals(a, b));   //对于多维数组，需要使deepEquals来进行深层次判断
}
```
