# 排序算法总结与C++中sort的运用
## 一、排序算法总结

### 稳定排序与非稳定排序

**定义**：那些相对位置是否发生改变（不影响排序结果的元素，即相同元素）的排序。
**稳定排序**：插入排序，冒泡排序，归并排序，基数排序。
**非稳定排序*：选择排序，希尔排序，快速排序，堆排序。
### 排序算法的内外部排序

**定义**：排序算法中，是否使用了额外的存储空间（存储空间的大小与排序的数组数量有关），外部排序能在大数据中进行排序，也就是说借用到了硬盘排序，不需要将所有数据都放入内存中才进行排序。
**内部排序**：插入排序，冒泡排序，选择排序，希尔排序，堆排序，快速排序。
**外部排序**：归并排序，基数排序。
## 二、C++中sort的运用
**从小到大排序**

```cpp
sort(arr,arr+10);//传入排序范围的首地址和尾地址
```

**从大到小排序**

```cpp
sort(arr,arr+10,greater<int>());
```
