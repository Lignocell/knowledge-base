# 希尔排序（分组插入排序）

---

## 一、概述
希尔排序，本质上就是分组插入排序：
- 具体一点，就是将数组进行分组，然后再每个组的内部实现插入排序。- 第二步，改变分组的步长，即原来是每个元素之间相隔三位，现在*缩小**间隔，再一次实现插入排序。- 最后，当步长为**1**时，停止排序。
## 二、步骤
当我们进行希尔排序时，我们需要推算，关于步长的选择，一个好的步长，能够优化希尔排序的时间复杂度，在这里，有两个步长选取的方式。
### 希尔增量序列

初始增量为数组长度的一半（n/2），每次增量减半直到1。
**缺点**：时间复杂度可能会退化到O(n²），可能会出现重复比较的可能

### hibbard增量序列

增量为2^k^- 1（如 1, 3, 7, 15...），最大增量不超过数组长度。
**缺点**：计算稍微有点复杂，需要预先找到K值。
##### K值的计算

**示例**：假设数组长度`n = 10`

- `k=1` 等于`2^1 - 1 = 1`（合法）
- `k=2` 等于`2^2 - 1 = 3`（合法）
- `k=3` 等于`2^3 - 1 = 7`（合法）
- `k=4` 等于`2^4 - 1 = 15`（超过10，停止循环）
- **最优*：`k = 3`，对应最大增量为 `7`。
## 三、代码演示
### 希尔增量序列

```cpp
void shell_sort(vector<int>& arr)
{
    int n=arr.size();
    for(int gap=n/2;gap>0;gap/=2)//增量每次都减半    {
        for(int i=gap;i<n;i++)
        {
            int temp=arr[i];//赋值给temp
            int j;
            for(j=gap;j>=gap&&arr[j-gap]>temp;j-=gap)
              //j>=gap防止非法越界
              //arr[j-gap]>temp用来比较是否此时选取的元素是否比temp大，这是进行插入排序的前置条件            {
                arr[j]=arr[j-gap];//进行插入排序，即把前位数字赋值给后位
            }
            arr[j]=temp;//将temp赋值给前位数字
        }
    }
}
```

### hibbard增量序列

```cpp
void shell_sort(vector<int>&arr)
{
    int n=arr.size();
    int k=1;
    while(pow(2,k)-1<n)
    {
        k++;
    }
    k--;//将k退回到合法值内
    while(k>0)
    {
        int gap=pow(2,k)-1;
        for(int i=gap;i<n;i++)
        {
            int temp=arr[i];
            int j;
            for(j=gap;j>=gap&&arr[j-gap]>temp;j-=gap)
            {
                arr[j]=arr[j-gap];
            }
            arr[j]=temp;
        }        
        k--;
    }
}
```
