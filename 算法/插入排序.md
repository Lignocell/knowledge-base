# 插入排序

---

## 思路

- 与选择排序相同，将排序数字分为已排序区和未排序区。- 先假定第一个元素为已排序区，后面的数字为未排序区。- 遍历数组，当遍历到第三个数字时，将这个数字与第二个数字进行比较。- 如果比第二个数字大，则将已排序区往后推进一个数字；如果比第二个数字小，那么将这个数字与第一个数字比较，同理插入顺序中。- 继续遍历数组，直到结束。
## 解析

```c
void sort(int *arr,int l,int r)//l到人r是待排序区的元素范围
{
    for(int i=l+1;i<r;i++)//第一个元素不用作排序，直接进行第二个元素的遍历    {      
        int index=i;
        while(index>l && arr[index]<arr[index-1])
  //当index等于l时，证明已经到达了已排序区的最顶头，不能向左移动了；每次循环都要顶头一次。        {
           int temp=arr[index];
           arr[index]=arr[index-1];
           arr[index-1]=temp;
           index--;
        }
    }
}
```

如果当前数组本身是有序的，那么时间复杂度为O(n)，而最差呢，就是O(n<sup>2</sup>)。
实际操作下来，插入排序的时间与选择排序的时间相同。
---

## 代码优化

### 思路

- 当上述代码中`index>l`只有在循环到第一位时才会生效，所以我们将其做一次改进==。
- 先循环遍历数组，找到这个数组中的最小一位放到第一位中来，再进行不包含第一位的插入排序。
### 代码

```c
void modify_sort(int *arr,int l,int r)
{
    int min=l;
    for(int i=l+1;i<r;i++)
    {
        if(arr[min]>arr[i]) min=i;//找到最小值，更新索引为min
    }
//以下代码，为什么不直接将min代表的最小值与第一位互换，这涉及到了插入排序的稳定性，先打个问号。    while(min>l)//将min代表的最小值移动到第一位    {
        int temp=arr[min];
        arr[min]=arr[min-1];
        arr[min-1]=temp;
        min--;
    }
    
    for(int i=l+1;i<r;i++)
    {      
        int index=i;
        while(arr[index]<arr[index-1])
        {
           int temp=arr[index];
           arr[index]=arr[index-1];
           arr[index-1]=temp;
           index--;
        }
    }
}
```

此时时间复杂度为O(n)。
