# 冒泡排序

---

## 思路

- 由于冒泡排序是c语言老师必备讲的排序，我在这里列出我自己的思考方法。

- 首先先将指针指向第一个元素，然后将这个元素与下一个元素进行比较，如果后一个元素大，那么指针移向后一个元素，一直到最后一个元素。

- 然后重新遍历，将这次遍历的最大元素移动向倒数第二位。

## 代码

```c
void bubble(int *arr,int n)
{
    for(int i=0;i<n-1;i++)
    {
        for(int j=i;j<n-i-1;j++)
        {
            if(arr[j]>arr[j+1])
            {
                int temp=arr[j];
                arr[j]=arr[j+1];
                arr[j+1]=temp;
            }
        }
    }
}    
```

### 修正

```c
void bubble(int *arr,int n)
{
    for(int i=0;i<n-1;i++)
    {
        int cnt=0;//设置一个计数器
        for(int j=i;j<n-i-1;j++)
        {
            if(arr[j]>arr[j+1]) 
            {
                int temp=arr[j];
                arr[j]=arr[j+1];
                arr[j+1]=temp;                
            }
            cnt++;
        }
        if(cnt==0) break;//证明待排序区是有序的，不用排序
    }
}    
```
