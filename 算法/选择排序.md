# 选择排序

---

## 思路

- 先假定第一个数字为这行数组中的最小值，然后将它与后面的数字分割。- 分为已排序区和未排序区。- 然后进行未排序区。- 遍历时，先使用一个指针指向未排序区的第一号值，然后遍历，当找到一个数字比第一个数字小，更新指针。- 最后将指针所指向的这个值放到排序区的最后一位（也就是待排序区的第一位），将排序区往后挪动一位，重新循环。
## 代码

```c
#include<stdio.h>

void sort(int *arr,int l,int r)//l和r是待排序区的存储范围
{
    for(int i=l;i<r-1;i++)//当i=r-1的时候，证明排序已经到了倒数第二个，也就是说待排序区只剩下一个元素了，那就没有必要继续排序了。    {
        int index=i;//让index指向未排序部分的最小值        for(int j=i+1;j<r;j++)//去除假定的第一个值，然后遍历未排序部分。        {
            if(arr[j]<arr[index]) index=j;//更新索引，找到未排序部分的最小值。        }
        //交换
        int temp=arr[i];
        arr[i]=arr[index];
        arr[index]=temp; 
    }
}
```

时间复杂度为O(n<sup>2</sup>)，实际运行与插入排序的速度相同。
