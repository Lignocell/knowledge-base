# 基数排序

## 一、思路

- 在进行基数排序之前，要保证一个原则：相同元素的相对位置保持不变；比如原顺序是5在前，3在后面，那么要保证相同元素的顺序不能颠倒。
- 所谓基数排序，其实是先统计元素的个位，先按照个位的大小进行排序，然后统计十位，按照十位数作为基数进行排序。
- 第一步，统计元素的个位数，就是这串数组中，有几个元素个位为0，有几个个位为1，以此类推。
- 第二步，求前缀和，比如如下所示。
	```
	1 | 2 |  3
	3个 2个 4个
	求前缀和	1 | 2 |  3
	3  3+2  3+2+4
	3   5     9
	```

-	3、2、4就是前缀和，那么1为个位数的元素排在数组中的前三号位置上，2为个位数的元素排在数组中的第4~5号元素位置上，以3为个位数的元素排在数组的第6~9号元素的位置上。
	那么，最后一个个位数为1的元素排在3号位置上，最后一个个位数为2的元素排在5号位置上；最后一个个位数为3的元素排在9号位置上。	
- 第三步，从后向前遍历数组，依次将个位数为3的元素分门别类地放置在空数组中。
- 第四步，对十位数组进行基数排序，过程相同。
- 排序完成。
在真实的排序中，不一定非要是两位数字，*可以将四位数字分成两位*，以此类推。
## 二、时间复杂度

O(nk). k代表处理的轮数
## 三、代码演示
```cpp
void radix_sort(int *arr,int l,int r)
{
    #define K 65536//65536=2的16次方，因为整数的范围是0~65535，所以定义这个数字能够排序所有的整数范围
    int *cnt=(int*)malloc(sizeof(int)*K);//用于记录每种数字出现的次数    int *temp=(int*)malloc(sizeof(int)*(r-l));//临时存储数据    //第一轮排序    memset(cnt,0,sizeof(int)*K);//初始化cnt
    for(int i=l;i<r;i++) cnt[arr[i]%K]++;//对数组进行遍历，并记录每种数组存储的个数
    for(int i=1;i<K;i++) cnt[i]+=cnt[i-1];//求前缀和    for(int i=r-1;i>=l;i--) temp[--cnt[arr[i]%K]]=arr[i];//第一轮排序    memcpy(arr+l,temp,sizeof(int)*(r-l));
    //第二轮排序    memset(cnt,0,sizeof(int)*K);//初始化cnt
    for(int i=l;i<r;i++) cnt[arr[i]/K]++;//对数组进行遍历，并记录每种数组存储的个数
    for(int i=1;i<K;i++) cnt[i]+=cnt[i-1];//求前缀和    for(int i=r-1;i>=l;i--) temp[--cnt[arr[i]/K]]=arr[i];//第二轮排序    memcpy(arr+l,temp,sizeof(int)*(r-l));
    return;
}
```
