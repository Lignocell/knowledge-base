# 快速排序
## 一、思路

- 先选定数据流中的第一个元素作为基准值，将它拿出来。
- 将数组分区，左边的区域要求小于基准值，右边的区域要求大于基准值。
- 先设置两个指针分别指向头尾两个元素（头指针指向基准值的区域），尾指针向前遍历，当遍历到小于基准值的元素时，将它与头指针指向的元素进行互换。
- 然后让头部指针向后遍历，当遍历到大于基准值的元素时，进行互换。
- 依次交替运行，，当头尾指针相遇时，此时所指向的元素就是基准值。
- 进行递归算法，对前后两个区域分别进行快速排序。
## 二、时间复杂度

O(nlogn)~O(n^2^)。
每一次递归，用于分区操作的次数都是n（n-1等都被忽略）。
只有当每一层在左右分区时的元素个数相同时，此时，树的高度为logn
（数学上，每次问题规模减半，递归终止条件为规模为 1。设递归次数为k，则 n/2^k^=1, 解得 k=log~2~n）；

当每次个数极度不平衡时，那么树的高度为n层。
## 三、代码演示
```cpp
void quiet_sort(int *arr,int l,int r)
{
    if(r-l<=2){
        if(r-l<=1) return;
        else{
            if(arr[l]>arr[l+1]) swap(arr[l],arr[l+1]);//r指向的是数组空间的末尾，未必是最后一个元素。            return;
        }
    }
    int x=l,y=r-1,z=arr[l];//z表示基准值    while(x<y){
        while(x<y&&z>arr[y]) --y;
        if(x<y) arr[x++]=arr[y];
        while(x<y&&z<arr[x]) ++x;
        swap(arr[y],arr[x]);
        if(x<y) arr[y--]=arr[x];
    }
    arr[x]=z;
    quiet_sort(arr,l,x-1);
    quiet_sort(arr,x,r);
    return;    
}
```

## 三、快速排序的优化

1. 每一次，让头指针和尾指针找到一对元素，就是头指针找到比基准值大的元素，尾指针找到比基准值小的元素，让二者直接互换。
```cpp
void quiet_sort_v1(int *arr,int l,int r)
{
    if(r-l<=2){
        if(r-l<=1) return;
        else{
            if(arr[l]>arr[l+1]) swap(arr[l],arr[l+1]);//r指向的是数组空间的末尾，未必是最后一个元素。            return;
        }
    }
    int x=l,y=r-1,z=arr[l];//z表示基准值    do
    {
        while(arr[x]<z)++x;
        while(arr[y]>z)--y;
        if(x<=y){
            swap(arr[x],arr[y])
            x++;
            y--;
        }
    }
    while(x<=y);
    //到这一步，说明x到了基准值的后面，y到了基准值的前面
    arr[x]=z;
    quiet_sort_v1(arr,l,x);
    quiet_sort_v1(arr,x,r);
    return;    
}
```

2. 优化基准值的选择，使用三点取中法计算出数据流中中间的元素作为基准值，进而优化时间复杂度。
```cpp
int three_point(int a,int b,int c){
    if(a>b) swap(a,b);
    if(a>c) swap(a,c);
    if(b>c) swap(b,c);
    return b;
}

void quiet_sort_v2(int *arr,int l,int r)
{
    if(r-l<=2){

        }
    }
    int x=l,y=r-1,z=three_point(arr[l],arr[r-1],arr[(l+r)/2]);//z表示基准值    do

    }

    return;    
}
```

3. 单边递归法：只在左边进行递归操作，右边区域在本层进行排序，也就是说节省一次递归操作。
```cpp
int three_point(int a,int b,int c){
    if(a>b) swap(a,b);
    if(a>c) swap(a,c);
    if(b>c) swap(b,c);
    return b;
}

void quiet_sort_v3(int *arr,int l,int r)
{
     if(r-l<=2){
        if(r-l<=1) return;
      else{
        if(arr[l]>arr[l+1]) swap(arr[l],arr[l+1]);//r指向的是数组空间的末尾，未必是最后一个元素。       return;
          }
        }
    while(l<r)
    {

        int x=l,y=r-1,z=three_point(arr[l],arr[r-1],arr[(l+r)/2]);//z表示基准值        do
        {
        while(arr[x]<z)++x;
        while(arr[y]>z)--y;
        if(x<=y){
            swap(arr[x],arr[y])
            x++;
            y--;
        }
        }
        while(x<=y);
    //到这一步，说明x到了基准值的后面，y到了基准值的前面
        arr[x]=z;
        quiet_sort_v3(arr,l,x);
        l=x;//将右半边的起始值改为x
    }
    return;    
}
```

4. 当元素个数少于6个时，会发现，快速排序的执行效率会比插入排序慢很多，所以当进行快速排序时，将小数据范围时改成插入排序。
```cpp
//无监督的插入排序
void modify_sort(int *arr,int l,int r)
{
    int min=l;
    for(int i=l+1;i<r;i++)
    {
        if(arr[min]>arr[i]) min=i;//找到最小值，更新索引为min
    }
//以下代码，为什么不直接将min代表的最小值与第一位互换，这涉及到了插入排序的稳定性，先打个问号。    while(min>l)//将min代表的最小值移动到第一位    {
        int temp=arr[min];
        arr[min]=arr[min-1];
        arr[min-1]=temp;
        min--;
    }
    
    for(int i=l+1;i<r;i++)
    {      
        int index=i;
        while(arr[index]<arr[index-1])
        {
           int temp=arr[index];
           arr[index]=arr[index-1];
           arr[index-1]=temp;
           index--;
        }
    }
}
```
