# 归并排序

## 一、思路

- 当面对大数组排序时，可以将大数组进行分割，分割成两个小数组，如果此时还是比较大，还可以继续向下分割，当分割后每个数组都足够小时，此时进行排序。- 然后，当每个小数组都排序完成后，让每两个数组进行归并，并拷贝回原区间，以此类推，最后合并为以一个有序的大数组。
## 二、时间复杂度

O(nlogn)。
## 三、代码演示
```cpp
void merge_sort(int *arr,int l,int r){
    if(r-l<=1) return;
    int z=(l+r)/2;
    merge_sort(arr,l,z);
    merge_sort(arr,z,r);
    int p1=l,p2=mid,k=0;
    int *temp=(int *)malloc(sizeof(int)*(r-l));//定义一个结果数组，将排序好的结果放置在其中。    while(p1<mid||p2<z){
        if(p2==z||(p1<mid&&arr[p1]<arr[p2])){//两种p1放置情况，第一种是，p2数组是一个空数组，第二种是当p1的元素小于p2的元素            temp[k++]=arr[p1++];
        }
        else{
            temp[k++]=arr[p2++];
        }
    }
    for(int i=l;i<r;i++) arr[i]=temp[i-l];//将排序结果放置回原数组当中    free(temp);
    return;
}
```

## 四、代码优化
因为开辟temp是比较耗时的，那么只要在函数外开辟一个足够大的空间，然后在函数内部使用就可以优化时间复杂度
