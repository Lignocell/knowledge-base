# 264.丑数Ⅱ

---

## 一、题目

给你一个整数`n` ，请你找出并返回第`n` 个**丑数** 。

**丑数** 就是质因子只包含 `2`、`3` 和`5` 的正整数。

 

**示例 1，*

```
输入：n = 10
输出：12
解释：[1, 2, 3, 4, 5, 6, 8, 9, 10, 12] 是由前 10 个丑数组成的序列。
```

**示例 2，*

```
输入：n = 1
输出：1
解释， 通常被视为丑数。
```

## 二、解析

### 思路

本题可以看作是一个小顶堆，结构如下图所示。

```
            1
      /     |    \
     2      3     5
   / | \   / \     |
  4  6 10 9   15   25
```

同时继续向下计算，每个子节点分别乘以2、3、5，形成一个小顶堆：

与此同时，规定每个子节点都不允许乘以比他们的质因子丑数还要小的数;
比如，的下一位子节点不允许乘2（使得不会出现重复的丑数）

本题设立一个容器来存放这些节点，同时进行分类存放，最后计算出需要的结果。

### 代码

```cpp
class Solution {
public:
        int nthUglyNumber(int n) {
            set<long long>s;
            long long flag=0,ans=0;//flag作为分类标记，ans则作为第一个丑数来保存
            s.insert(1);//插入首节点
            while(n--){
                ans=*s.begin();
                s.erase(s.begin());
                if(ans%5==0) flag=2;
                else if(ans%3==0) flag=1;
                else flag=0;
            }
            switch(flag)
            {
                case 0:
                    s.insert(ans*2);
                case 1:
                    s.insert(ans*3);
                case 2:
                    s.insert(ans*5);
            }
            return ans;
        }
}
```
