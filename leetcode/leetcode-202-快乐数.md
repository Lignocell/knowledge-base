# 202.快乐数字

## 一、题目

编写一个算法来判断一个数 `n` 是不是快乐数。

**「快乐数」* 定义为：

- 对于一个正整数，每一次将该数替换为它每个位置上的数字的平方和。
- 然后重复这个过程直到这个数变为1，也可能陷入**无限循环** 但始终变不到 1。
- 如果这个过程 **结果为* 1，那么这个数就是快乐数。

如果 `n` 是*快乐数 就返回`true` ；不是，则返回`false` 。

 

**示例 1，*

```
输入：n = 19
输出：true
解释：
12 + 92 = 82
82 + 22 = 68
62 + 82 = 100
12 + 02 + 02 = 1
```

**示例 2，*

```
输入：n = 2
输出：false
```

---

## 二、解析

### 思路：

将每个数字都当作是一个链表的节点，将1替换成NULL，此时，这道题就可以变成leetcode-141-环形链表了，两个指针赛跑，如果是快乐数，则证明可以到达NULL，即单向链表，反之，则被称为环形链表。

### 代码：

```cpp
class Solution {
public:
int getNext(int n)
{
    int sum=0;
    while(n>0)
    {
        int bit=n%10;
        sum=sum+bit*bit;
        n=n/10;
    }
    return sum;
}

    bool isHappy(int n) {
        int p=n;
        int q=n;
        while(p!=1)//p等于1时，相当于NULL，即空链表
        {
            p=getNext(getNext(p));
            q=getNext(q);
            if(p==q&&q!=1) return 0;//如果 q 等于 1，意味着我们找到了一个快乐数，程序应该继续执行而不是返回 0。
        }
        return 1;
    }
};
```
